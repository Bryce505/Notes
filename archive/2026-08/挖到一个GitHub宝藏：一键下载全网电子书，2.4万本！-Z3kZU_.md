找电子书这事，我估计不少人都折腾过。搜索引擎里输入书名加 epub，翻出来前几页全是引流站，点进去让你关注公众号，关注完甩你一个网盘链接，好不容易下载下来，解压还要密码，密码藏在他朋友圈广告里。我之前为了找一本书能耗进去半个小时，最后书没找着，微信里多了一堆不知道什么时候会开始发广告的号。

后来我在 GitHub 上翻到一个项目，叫 ebook-treasure-chest，中文名就叫电子书下载宝库。名字起得很直白，干的事也很直白：把散落在各个电子书网站上的下载链接收拢到一起，分好类，摆在一个能搜的页面上。

这个项目到底是什么

先说清楚一件事，这个仓库本身不存书，它存的是书目的索引和下载链接。维护者从各个电子书网站上把链接收集起来，给每本书打上分类标签，整理成结构化的数据放在仓库里。

收录的非常全，我打开它的统计页面看了一下：总书籍数 24,071 本，分类数量 1000 个，全是中文书。每本书基本都准备了 epub、mobi、azw3 三种格式，这个后面细说。

书目来源这块，按项目的说法，覆盖了帆书 app（就是原来的樊登读书）、微信读书、京东读书、喜马拉雅这些平台的大部分电子书。我抽查了几本自己读过的，樊登讲过的《可复制的沟通力》、刘润的《底层逻辑》这类书确实都在。文学、历史、科普、管理这些大类下面的存量也比较扎实，文学类 2711 本，历史类 1748 本，不像有些书单，分类名头起得挺响，点进去没几本。

项目在 GitHub 上拿了 1.6 万多的 star，从 2023 年维护到现在还在更新，不是烂尾工程。

功能这块，我挨个说说

实时搜索 - 边打字边出结果

项目配了一个 GitHub Pages 的在线搜索页面，这是我觉得整个项目最值钱的部分。两万四千多本书，如果靠在 GitHub 页面上 Ctrl+F 翻，找到天黑也找不到几本。这个搜索页打开就是一个输入框，输入书名、作者或者分类关键词，结果即时刷新，不用回车，不用点按钮。

我试了搜「沟通的艺术」，相关的书立刻列出来一排；搜作者名也一样好使。每本书的条目里直接写着作者、所属分类，底下就是下载按钮。

多关键词搜索 - 空格隔开就能组合

搜索支持多个关键词一起输，中间用空格隔开。比如我搜「沟通 樊登 职场」这三个词，命中的就是同时沾边的书，一页下来基本就是我要的那本。书单大了以后这个功能很实用，单关键词经常搜出来几十条，加个作者名或者分类词，范围一下就收窄了。

分类目录 - 1000 个分类，能当书单翻

除了搜索，项目还给了一个完整的分类索引。1000 个分类听着夸张，但它不是凑数的，除了文学、历史、推理、心理这些大类，往下还有很细的标签，像「敦煌」「蜡烛图」「烘焙」这种细度的标签都有。闲的时候不看具体某本书，顺着分类翻也挺有意思，我经常是冲着一本书去，翻着翻着顺手存下来三四本别的。

在线页面上默认显示前 20 个热门分类的书，每个分类先列 10 本，剩下的靠搜索找，这个设计我觉得合理，全铺开页面就没法看了。

三种格式 - 主流阅读设备都照顾到

每本书都给 epub、mobi、azw3 三种格式。epub 最通用，手机上的阅读 app 基本都认；mobi 和 azw3 主要是给 Kindle 用户准备的。我自己是用手机加一台老 Kindle，两种设备都能直接下直接看，不用再去转格式。找过书的人都知道，找到一个链接结果格式不对、还得自己拿 Calibre 转一道，是很扫兴的事。

什么情况下它特别好使

Kindle 用户找书。 Kindle 商店里的中文书不算全，很多书有 epub 没 mobi。这里三种格式一起给，省下转格式这一步，丢进 Kindle 就能看。

通勤路上想读点东西的。 帆书、喜马拉雅上听过的书，想找原文细看，直接搜书名，大概率有。

写东西查资料。 我有时候需要翻某本书里的具体章节，手头没书，买一本等快递又来不及，先去这里下一本翻一翻，确认内容对路了再决定要不要买纸书放书架上。

不知道读什么的时候。 1000 个分类当书单逛，比算法推荐的书单有意思，至少不会翻来覆去就推那几本畅销的。

我的看法

这个项目本身没什么技术门槛，说白了就是一个整理得很勤快的索引。但它确实解决了一个实际问题：中文电子书太分散，很多还藏在各种引流套路后面。它把链接收在一起，放在一个能搜的页面上，不收钱，不要关注。维护者从 2023 年一直整理到现在，两万四千多本书，这个工程量是实打实的。

当然也有要交代的话，书毕竟是人家一本一本写出来的，这个库里的链接来自第三方站点，版权情况比较复杂。我的建议是把它当成一个「试读和找书」的工具：正版渠道买不到的、想先翻翻再决定买不买的，用它很方便；真正读下来觉得好的书，还是去微信读书开个会员或者买本纸书支持一下作者，这个度大家自己把握就行。
