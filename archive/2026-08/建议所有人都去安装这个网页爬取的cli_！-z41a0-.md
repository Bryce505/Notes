01 · 先科普一下 Skill 和 CLI 的区别

在介绍它之前，我想先 科普一下 Skill 和 CLI 的区别 。

如果你之前安装过飞书 CLI 或者瑞幸的 CLI，你应该有所体会： CLI 是一个系统层面的调用 ，一次安装，全局共享，它的调用比 Skill 要更加简单，也不需要你在多个 AI 软件里反复安装。

如果你自己需要做封装的话， Skill 适合接口不多的场景 ， CLI 适合接口较多的场景 。

[图片]

— CLI 一次安装，全局共享

CLI 提供的是执行能力 ， skill 提供的是可发现性 。

所以你会发现，在安装 Dokobot 时，需要先安装它的 CLI，然后再去技能商店里安装每个技能独立的 skill。
