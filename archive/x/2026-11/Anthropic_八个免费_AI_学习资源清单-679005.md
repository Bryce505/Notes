虽然我很讨厌 Anthropic，但是它这 8 个 AI 学习网站，真的值得所有新手收藏

前面我推荐了 Anthropic 官方的 5 篇 AI Agent 入门文章，没想到大家的反馈都很好

所以我就直接把我收集到的 Anthropic 的网站和课程分析出来了，你研究下去你会发现它提供的学习资源远不止技术文章，甚至还有免费的系统课程、中文教程、Agent 开发文档和开源项目

达里奥虽然不厚道，但是 Anthropic 给的资料和学习内容还是十分厚道的，最主要很多资料都有中文版本，尤其是课程和内容质量都有保障

这里我整理了 8 个 比较不错的课程和内容

1、Claude Academy｜免费 AI 学习课程

我最推荐新手从这里开始，有系统的 AI、Claude Code、Agent Skills 和 MCP 课程，部分还提供中文内容

https://academy.claude.com/

2、Anthropic Engineering｜AI 技术文章

这里是我平时比较喜欢看的地方，主要分享 Agent 架构、Harness、上下文工程和各种 AI 技术实践，内容质量很不错

https://www.anthropic.com/engineering

3、Claude Code Docs｜AI Coding 教程

从 Claude Code 安装、CLAUDE.md、Skills、Hooks 到 Subagent 都有详细的教程，适合想学习 AI 编程的朋友

https://code.claude.com/docs/en/overview

4、Claude Platform Docs｜Agent 开发文档

如果你想自己开发 AI Agent，可以从这里学习 API、工具调用、SDK 和相关的开发技术

https://platform.claude.com/docs/en/home

5、Anthropic Research｜AI 前沿研究

这里主要是 Anthropic 发布的研究成果和论文，包括模型能力、AI 安全、Agent 行为等，适合有一定基础的朋友

https://www.anthropic.com/research

6、Claude Resources｜AI 实际应用案例

主要分享各种 AI 使用案例、指南和视频，比较适合不想一开始就研究复杂技术的小白

https://claude.com/resources

7、Claude Cookbooks｜AI 开源实战案例

Anthropic 官方维护的 GitHub 项目，包含大量代码示例，比如 RAG、工具调用、Agent 工作流等，可以直接拿来学习和参考

https://github.com/anthropics/claude-cookbooks

8、Anthropic Skills｜官方 Skills 开源库

如果你对 Skills 感兴趣，我推荐看看这个仓库，可以学习别人怎么设计 Skill、编写 SKILL.md，以及组织相关工具和脚本

https://github.com/anthropics/skills

如果你不知道从哪里开始，我也简单整理了 3 条学习路线：

1、小白入门：Claude Academy → Claude Resources → Claude Code Docs

2、AI Agent 开发：Engineering → Platform Docs → Claude Cookbooks

3、Harness 深入研究：Engineering → Research → Anthropic Skills

其实这些资源并不需要全部学完，根据自己的兴趣和需求选择就可以了

我觉得 Anthropic 最大的优点之一，就是愿意把很多技术思路和实际案例公开分享出来，而且很多文章写得比较通俗易懂

还是那句话，公司虽然很垃圾，但是内容确实值得看，取其精华，去其糟粕

尤其是刚开始学习 AI 和 Agent 的朋友，我觉得这些免费资源已经足够作为一个不错的学习起点了

昨天我搜索资料的时候，发现 Anthropic 官网上提供了非常多优秀的文章，尤其是针对 AI 领域的内容都写得比较好，而且最大的优点就是通俗易懂

我从里面选了 5 篇最值得新手阅读的文章，如果你也想学习 AI Agent，可以从这里面开始看

1、Building effective agents｜构建高效的 AI Agent

我最推荐新手阅读的一篇文章，讲清楚了 Agent 和 Workflow 的区别，以及 5 种常见的工作流设计模式，适合刚开始学习 Agent 的人

https://www.anthropic.com/engineering/building-effective-agents

2、Claude Code: Best practices for agentic coding｜AI 编程最佳实践

主要介绍怎么正确使用 Claude Code，包括项目配置、任务规划、工具调用和代码验证，适合想学习 AI Coding 的新手

https://www.anthropic.com/engineering/claude-code-best-practices

3、Equipping agents for the real world with Agent Skills｜Agent Skills 入门

如果你还不理解 Skill 是什么，可以看看这篇，讲清楚了 Skill 的基本结构、SKILL.md 和按需加载机制，以及怎么给 Agent 扩展能力

https://www.anthropic.com/engineering/equipping-agents-for-the-real-world-with-agent-skills

4、Effective context engineering for AI agents｜Agent 上下文工程

主要讲解上下文管理，为什么上下文不是越长越好，以及怎么通过信息检索、工具管理和上下文压缩，让 Agent 运行得更加稳定

https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents

5、How Anthropic teams use Claude Code｜Anthropic 内部 AI 使用案例

这篇更偏向实际应用，分享 Anthropic 内部不同团队怎么使用 Claude Code，包括编程、产品、设计和日常工作，即使没有编程基础也可以参考

https://www.anthropic.com/news/how-anthropic-teams-use-claude-code
