前言

住宅IP太贵？号商买的价格也不低？想长期低成本持有Claude订阅？
保姆级性价比方案来了：节点自己搭，账号自己注册，走官方渠道开 Pro。已经稳定用了两个月，手机和电脑都在用。

费用也很直接：Pro 订阅按每月 20 美元准备，VPS 按活动价找，一年 10～20 美元。服务器摊到每个月，也就多一美元左右，整体是每月 20 美元出头；礼品卡的实际人民币价格看下单汇率。

给大家看看我这两个月的使用情况,非常稳定

[图片]

先说整体思路：这套方案分四段走。

网络自己搭，账号自己注册，订阅自己付。先把 RackNerd 的 VPS 买好，让 Codex 搭出 Hy2 节点；再注册美区 Apple 账号，手机端用 Karing 连自己的节点，注册 Claude。账号先每天简单用两句，放几天，再买礼品卡开 Pro。最后把电脑的 DNS、时区和登录都处理好，日常电脑端就用 Claude Code。

机房 IP 我照样用。我不会一上来就把住宅 IP 当成必需品，自己选网络时，我更看重这两件事：

第一，IP 要稳定。

我会尽量固定用自己的一个节点，手机和电脑也用同一个出口。今天美国、明天新加坡，节点和地区换来换去，这种机场用法我会避开。自己的节点放在哪、什么时候换，我心里有数。

第二，尽量把 IP 的使用管在自己手里。

大家常说的“IP 纯净度”，对我来说，最实际的就是少跟不认识的人混着用。共享节点上还有谁、他们在做什么，我看不到；自建独享，至少当前是谁在使用、怎么使用，我自己能控制。所以我优先选自己搭、自己用。新分配的 IP 过去有没有使用记录，还是另一回事。

以后如果这个机房出口真不好用了，自建的网络也不用推倒重来。可以保留自己的 Hy2 节点作为前段，再接一个住宅代理做最后出口：手机／电脑 → 自建 Hy2 节点 → 住宅代理 → Claude

这样可以把自己接入的线路和最后对外的 IP 分开调整。住宅代理负责最终出口，前面仍然走自己熟悉的节点。至于这条链比直连住宅代理快多少、稳多少，到时拿实际线路对比，不靠多套一层就下结论。

我现在先把自建机房节点这套讲清楚，住宅链式代理留作后续升级。开始前准备一台能用 Codex 的电脑、一部 iPhone、自己的邮箱和能收验证码的国内手机号。

第一章｜网络

1. 买 RackNerd，先找优惠。

第一个坑先说在前面：别一打开官网，就从常规套餐里选一台付钱。先搜“RackNerd 优惠券”“RackNerd 年付优惠”或“RackNerd Black Friday”，找活动套餐。

我现在会先按 10～20 美元一年的预算去找。最近他们家有涨价，不急可以再等等。便宜套餐有时要走专门的活动入口，不一定需要再填优惠码。找到后回到 racknerd.com 或 my.racknerd.com 的官方页面下单，看最后的年付金额。

套餐先看入门配置，拿来搭自己用的节点就行。选好机房和 Linux 系统，再确认包含 IPv4，价格是每年，不是每月。看到 Sold Out 或 0 Available，就换活动入口或等补货。

第二章｜账号

1. 注册美区 Apple 账号。

已有美区账号就跳过。没有的话，到 account.apple.com 创建一个，用自己的邮箱和国内手机号。国家或地区选 United States（美国），手机号区号单独选中国 +86，银行卡选无、账单地址使用地址生成器生成一个美国免税州地址。姓名、生日和密码填好后，完成邮箱和短信验证。

美国免税州地址生成器 | 免费生成真实免税州地址、邮编、电话 - MockAddress

[图片]

然后在 iPhone 打开 设置，点右上角头像，退出当前苹果账号，再登录新注册的美区账号。

2. 下载 Karing，导入自己的节点。

用这个美区账号到 App Store 搜索并下载 Karing。

把刚才 Codex 给的 hy2.yaml 发到手机，保存到“文件”App。打开 Karing，进入“添加配置”，选择“导入配置文件”，找到 hy2.yaml 并保存。

回到主页面选中自己的节点，打开连接。第一次会提示添加 VPN 配置，允许后继续。再检查一次公网 IP，确认走的是自己的 VPS。

[图片]

3. 注册 Claude，把中转邮箱记下来。

保持 Karing 连接，在美区 App Store 下载官方 Claude，确认开发者是 Anthropic。打开后点使用apple继续。

注册完成，马上到 Claude 设置里把账号邮箱记下来。这里看到的 Apple 转发地址，就是后面电脑登录要填的“中转邮箱”。只记前面的就行，后面看不清的是固定地址，形如：xxxxx@privaterelay.appleid.com。

同时记清它转发到哪个实际收件箱。后面登录时：填的是中转邮箱，收信去 Apple 绑定的那个邮箱。

[图片]

4. 每天简单问两句，先放两天别订阅

我的顺序是先注册，每天正常问两句，放几天，再去做支付这一步。注册当天先不急着买 Pro。

这几天就拿它处理小问题：改一段文字、解释一个概念，或者帮你理一理思路。正常用就行。

第四章｜日常使用

[图片]

手机已经能用 Pro，接下来处理电脑。我按这个顺序来：先把 DNS 问题解决，再对好时区，最后登录 Claude Code。

1. 先让 Codex 检查并解决 DNS 泄露。

电脑也导入同一份 hy2.yaml，选中自己的节点。Clash 用支持 Hy2 的 Mihomo / Clash.Meta 内核版本，Karing 也直接从文件导入。

有时网页已经连上节点，DNS 还是沿着另一条路出去。所以我会让 Codex 把电脑、代理软件和浏览器一起检查，改完再实际测。直接把下面这段发给它：

请先帮我检查并处理这台电脑的 DNS 泄露问题。
我现在用的是自己的 Hy2 节点，代理软件是：[Clash]。

保持当前节点不变，先记录出口 IP，再检查系统 DNS、代理软件 DNS、浏览器安全 DNS、IPv6，以及终端实际使用的代理。
请备份要修改的配置，按当前软件的实际能力处理 DNS 和路由问题，不要只把 DNS 地址换成一个公共 DNS 就算完成。

修改前后都打开真实的 DNS 检测页面，并结合客户端连接或日志核对 DNS 请求路径；再检查浏览器和终端的实际出口。给我修改前后的检测结果和改了什么。

处理完成后，按出口 IP 对应的城市确认应使用的电脑时区，告诉我下一步如何设置。

2. 把电脑时区改成 IP 所在地的时区。

先看节点出口 IP 显示在哪个城市，再把电脑时区设到对应地区。这里看的是 VPS 的实际出口，不是支付宝选的旧金山。

Mac：系统设置 → 通用 → 日期与时间，关闭按当前位置自动设置时区，再选对应城市。Windows：设置 → 时间和语言 → 日期和时间，关闭自动设置时区，在时区列表里选择对应地区。

改的是时区，自动校时继续开着；有夏令时的地区按系统规则调整，别手动把系统时间拨快或拨慢。也可以直接让 Codex 按你的系统处理。

3. 用中转邮箱登录 Claude Code。

让 Codex 检查电脑上是否已有官方 Claude Code；没有就让codex安装，已有就沿用。还要确认终端请求通过自己的节点，按 Clash 或 Karing 的实际端口配置 HTTP／HTTPS 代理。

打开终端输入 claude 启动，按提示选择使用 Claude 订阅账号。已经打开过的，可以在 Claude Code 里输入 /login。浏览器会打开登录授权页面。

claude

拿出第二章记下的中转邮箱，选择邮箱登录，把它填进去。Claude 会把登录邮件发到这个地址，再由 Apple 转发到和账号绑定的实际收件箱。

所以，登录时填中转地址；找邮件验证码时，打开的是你平时用的那个邮箱。别把这两个地方弄反。

4. Gmail 收不到，去垃圾邮件里找。

如果绑定的是谷歌邮箱，收件箱没看到 Claude 的邮件，先去垃圾邮件看看。我会直接按这两个入口找：

电脑 Gmail：左侧“更多” → “垃圾邮件”。

手机 Gmail：左上角菜单 → “垃圾邮件”。

5. 拿到验证码，回电脑完成登录。

这里我用手机收邮件：打开 Claude 登录邮件，点里面的登录链接。跨设备打开时，页面会给出用于刚才电脑登录页面的验证码。把它填回电脑，继续完成浏览器里的 Claude Code 授权，再回到终端。

看到 Claude Code 的输入框后，先问一句“用三句话解释一下，你能帮我做什么”，确认能正常回复，再开始自己的任务。

后面日常使用，连上自己的节点，打开 Claude Code 就行。网络自己搭，账号自己拿着，订阅也在自己手里。
