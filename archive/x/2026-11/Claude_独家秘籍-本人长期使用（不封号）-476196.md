二、详细教程(以Mac为例)

2.1  第一层梯子

我觉得从这种表达可能更好理解吧，第一层梯子就是你平常上网实用的 VPN，比如快连、oppa 等这种科学上网的科学上网梯子，一般都不使用全局代理（访问外网才需要走代理，平常的网站是不需要走梯子的代理模式），只要你在 X 能看到我文章，说明你已经实用了 VPN，所以第一层梯子是大家基本都是有的。

2.1 第二层梯子

第二层梯子特别重要，这是为了我们绑定一个固定 IP 等重要环节，简单理解就是从第二层梯子出站后再走第一层梯子网络，先去 github 下载开源工具：https://github.com/2dust/v2rayN/releases  下载最新版即可。

下载了之后你需要一个稳定的 IP，尽量是家庭的 IP，这个购买渠道大家可以自行去找，我用的是 webshare ，购买的独享家庭 IP（我发现从webshare 购买也可能买到机房 IP，但我发现有的机房 IP 也不封号），webshare 现在挺缺货，我看今天又补了美国的家庭 IP，我也是购买的美国家庭 IP，想走我连接注册的可以使用：https://www.webshare.io/?referral_code=uw82bwdctq46  不走也无所谓，IP 是一定要有一个稳定的，不能漂移，这是所有环节中最重要的一环，也是为什么第一层梯子不能用的原因（经常漂移），这个先配置上后面会讲配置它都意义以及如何使用。

购买的 IP 可以使用 ：https://ip.net.coffee/claude/ 检查你的 IP 质量（虽然可能没啥实质性作用）

2.5 CLAUDE支付

全的，不建议走 U 卡，Claude 仅知道你的支付渠道，所以我们需要先在 ipone 下载 claude ，这里下载 claude 的时候是需要一个 海外的 icloud 账号，由于上面 IP 是美国的，所以在 App Store 中也要使用 美国地区的 Apple 账号，至于如何注册美区的 Apple 可自行搜索网站，注册就是几分钟的事。此处有个小细节，我们可以从 ipone 的媒体与购买项目 退出 Apple 账号，然后去 AppleStore 中登录你海外 iclaude 账号（一定要从 AppleStore 登录）这样设置是你的自身 icloude 账号,商店是你的海外账号。

大体流程就是：支付宝切到“旧金山”，然后找到 Pockyt Shop，去买 20 刀以上的礼品卡然后充值到 AppleStore 里的账户，最后在 Claude APP 中走订阅支付，一定要选择 Pro 的支付（ 20刀），一定不要选择 5x 20x max 特别容易触发风控。

2.6 环境变量设置

打开 “终端”输入 open ~/.zshrc  会弹出我们的系统变量文件，然后在最下面加一段映射代码，目的是为了让 claude 全部走本地 10808 端口出站：

alias claude='http_proxy=http://127.0.0.1:10808 https_proxy=http://127.0.0.1:10808 HTTP_PROXY=http://127.0.0.1:10808 HTTPS_PROXY=htp://127.0.0.1:10808 no_proxy=localhost,127.0.0.1,::1,.local NO_PROXY=localhost,127.0.0.1,::1,.local claude'

保存后再“终端”再输入 source ~/.zshrc  命令，将系统配置重新加载在缓存中，这样 claude 就每次会出站的端口控制住了。

第一步下载：/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

第二步配置环境：echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zshrc

source ~/.zshrc

第三步验证：关闭终端，再打开新的终端 输入 brew -v 验证

第一步下载：brew install --cask claude-code

第二步验证：claude --version

2.8 注意事项

1、开通 claude pro 会员后，尽量先使用一个月，之后如果你不够用，则再一个月后再开 5x max，一定不要开 20x，会触发人脸以及风控；

2、不要使用 claude 的客户端，触发风控比较大，所以只建议使用 cli 模式；

3、按照我的教程一步步来是没问题，里面可能有一些细节不是很详细，可以在自行查找。

到此为止 claude 已经可以使用了，目前为止 opus5 是最经济的（据说 比 4.8 都省 40% 左右），而且还快速，使用下面命令可以不用每次找你授权使用：

claude --model claude-opus-5 --dangerously-skip-permissions
