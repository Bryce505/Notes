一、开始前备好这几样

付钱之前先看手头齐没齐：

✅ 能付外币的卡，Visa、Mastercard 或 U 卡都行，我首月付了 $4.09

✅ 现有节点或海外 VPS，拿来当前置加密跳板，我家跑的是 DediRock 美国 VPS

✅ 新版代理客户端，没 VPS 的装 Clash Verge Rev（2.4.5 及以上），我家是 Mac mini 跑 Surge

买之前说句实在话，美国居民家里光猫拨出来的才叫真家宽，那种公网 IP 隔阵子还会变。Webshare 这种静态住宅代理，是把 Comcast 这类宽带商的住宅号段租下来、放进数据中心机房里跑。

选 Static 地址才固定不变，选 Dedicated 租期内才只分给你一个人用、不跟别人拼车。图个干净固定的美国住宅段出口，买它够用；指望连进美国居民家里路由器的，这钱别花。

四、挑完锁死 IP 再抄密码

这时候还没配代理客户端，直接把「Proxy List」里分到的那串 IP 复制下来，贴进 checkip.0xmason.com 的查询框就能查 ASN 和是不是机房，不用等连上再测。

第一条系统分的是 Cox，我当时想碰碰 Comcast 或 AT&T，没多想先换了一次，结果分到一条 Wave Broadband（AS11404）。

Wave 差点把我骗过去。当时在 ip-api 查出来不是托管机房，Scamalytics 欺诈分更是 0/100，可同一页把 Server 标成了 Yes。我贴进 checkip.0xmason.com 一查，直接被归进 IDC 机房。

花钱买个机房标图啥，直接再换。

对上 Comcast 就能收手了，第一件事先把自动替换关死。

五、没 VPS 接 Clash

想把 Webshare 挂在现有节点后面，客户端底层内核得是 Mihomo，直接装 Clash Verge Rev（2.4.5 及以上） 最省事。还在用早年停更的老 Clash 内核，它不认 dialer-proxy，别为了导入成功把这行删了，换 Clash Verge Rev 导入原订阅就行。

我用 Mihomo 测了自己管的几个节点：美国、香港两条 Hysteria 2 后面挂上 Webshare，各测 3 次出口全是我的 Comcast 地址；另一台日本 VLESS 单用能上网，串上 Webshare 连试两轮都没通。

前置串不通直接换一条。

⚠️ 不管走普通 HTTP 还是 SOCKS5 串接，前置节点那头都看得到你的 Webshare 代理账密。机场节点我只拿一条 Trojan 试过连通，能连到 Webshare 等输密码那步（返回 HTTP 407），但我不想把密码交出去，就没往下填。真要用机场节点串，只选信得过的；不放心就直接上自己的 VPS。

打开 Clash Verge Rev 点左侧「订阅」，右键当前订阅选「编辑节点」，用那四项新建一个 HTTP 节点，起名叫「Webshare固定出口」（如果贴的是 http://用户名:密码@地址:端口 格式，密码里带 @ 先换成 %40）。

再切到左侧「代理」页打开「代理链」，先点你的前置节点、再点「Webshare固定出口」，确认前置节点在上、Webshare 在下。

回到「订阅」右键同一份订阅：先在「编辑代理组」建一个手动选择组（比如叫「美国固定出口」）把这条链放进去，再点「编辑规则」在最前面加一条 DOMAIN,api.ipify.org,美国固定出口。用右键这几个菜单加进去的内容，以后更新订阅不会冲掉。

开系统代理、切「规则」模式，浏览器打开 api.ipify.org 查出口，再去客户端「连接」页点一次关闭全部连接（或关掉系统代理再重开），刷新网页再查一次。

两次都对上后台 IP 才算稳，有一回跳回原节点就是链没串上。

确认全通以后，回「编辑规则」把你要固定出口的域名（比如 DOMAIN-SUFFIX,x.com,美国固定出口）加在最前面；要是习惯切机场原有的策略组，就在「编辑代理组」里把这条链塞进对应分组再选中。别把默认总出口或视频流量全切过去，250 GB 不经刷。 以后换了前置节点，再去 api.ipify.org 核一遍。

六、有 VPS 自建接法

没 VPS 的直接跳过这节。

走自己 VPS 最大的好处，是两套密码完全分开。手机和电脑只填 VPS 域名和入站密码，Webshare 那四项只留在 VPS 上，我 iPhone 里连 Webshare 密码都没存。

这节默认你 VPS 上本来就在跑 Hysteria 2，有现成的域名和证书。原来的普通节点不动，在同一台机子上另开一个 UDP 端口专门转给 Webshare（拿 10443 举例，VPS 本机和云厂商安全组都要放行 UDP 10443），tls 直接复用原配置里的证书路径（新拷证书记得给 hysteria 用户读权限），配置存到 /etc/hysteria/webshare.yaml：

七、偶尔卡一秒别急着换 IP

偶尔顿一下，别急着点换 IP。

静态住宅代理建连偶尔慢一秒很正常，换一次就少一次额度。11 月 18 号晚上我在 DediRock 上直测 Webshare，确实抓到过一次慢连接：光等 TCP 接通就卡了 1,087 毫秒，接通以后代理应答只要 70 毫秒。

卡的是建连那一瞬，IP 本身压根没坏。前面把「临时变慢自动替换」关掉，就是防系统抖一下把 Comcast 换没了。

出站协议直接选 HTTP 就行，不用折腾 SOCKS5。我在 DediRock 上拿老 SOCKS5 跑 40 组，首字节中位数 438 毫秒；后来换成 HTTP，再加了一层本机小中继（就是开头图里标的「连出口慢时补连」，超过 350 毫秒没回就补连一次、空闲连接留 12 秒），同样 40 组整体压到了 239 毫秒。

这 239 毫秒带上了中继的效果，单换 HTTP 我没单独拆测。接回家里跑 36 次 HTTPS 全通，首字节中位数大概 574 毫秒，日常刷网页、登账户不差这零点几秒，照上面直连 HTTP 就够用了。
