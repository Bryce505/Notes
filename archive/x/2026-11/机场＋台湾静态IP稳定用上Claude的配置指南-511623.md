一、网络原理
IP 是你在网上的门牌号。静态 IP 就是固定不变、只有你一个人用的门牌号。
链式代理：先用机场出海，再从静态 IP 出去。Claude 只看得到最后那个静态 IP，不管你前面用的是什么机场。
为什么不直接用机场：机场的 IP 是一大群人共用的，一片 IP 被判了，换哪个节点都一样。
光有静态 IP 不行：它自己出不了海，国内直接连它连不上，必须接在机场后面。所以你原来的机场留着接着用，不用删。
机场节点尽量和静态 IP 选同一个地区，不然延迟很高。我实测两边都在台湾约44毫秒，机场换成美国节点要300多毫秒。
地区要选 Claude 支持的。我用的是台湾；香港、澳门 Claude 不支持，别选。

五、登录和封号
a. 封不封号不光看 IP，还看时区、浏览器环境，IP 只是一小部分原因，所以大家才用指纹浏览器。
b. 网页上登录 Claude，我用的是比特浏览器（就是一种指纹浏览器）。是 GPT 让我这么做、也是它帮我配的，直接和 GPT 提需求即可。
c. 电脑时区也要和你的节点（也就是静态 IP）保持一致：节点是美国的就用美国时区，是台湾的就用台湾时区。指纹浏览器的使用环境也让 GPT 按同一个地区配好。别自己弄，让 AI 改就行。
d. 这台电脑以前被封过号的，先把环境：浏览器缓存和 Cookie 清干净。同上让 GPT 干。
e. 说实话，这些都做到了也不保证不封，有人在美国都被封。只能尽人事听天命，所以付款要「上保险」。
