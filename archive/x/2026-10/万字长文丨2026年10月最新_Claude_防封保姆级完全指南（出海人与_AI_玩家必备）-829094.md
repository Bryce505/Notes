最近 Claude 做视频和代码能力封神，但国庆这轮封号，连用了两年的老号、刚充的 Max 也批量被封。挂着家宽、买着老号依然逃不过，因为风控本质上是一套多维打分系统，跳节点、DNS 泄漏、终端系统代理残留任何一项超标，都会触发连坐。

我趁着假期花了几天排查底层机制，确认了一件事：比起花大钱买家宽，时区、终端残留和退款退路才是保号核心。这篇不讲玄学，只讲实操，拆透四层防线与 11 步最低稳法（附排查命令与被封退款路径）。官方上半年封了 1140 万个账号，申诉推翻率只有十分之一，很多人以为说中文或 IP 不纯被封，其实真正致命的是时区撕裂、WebRTC 泄漏和终端代理残留。

1. 官方到底在封什么

社区爱讲指纹、家宽、老 Gmail、研究员号，有用的和玄学搅在一起。先看能查到官方原文的部分，帮助中心 Safeguards warnings and appeals 里写了三条封号理由：

反复违反使用政策（Usage Policy）

从不受支持的地点创建账号

违反服务条款

[图片]

消费者条款里还有几条同样硬：

不能把登录信息、API Key、凭据分享给任何人，也不能把账号借给别人

必须遵守 Supported Regions Policy（支持地区政策）

使用政策禁止：多账号协同规避检测、自动化注册、用新号绕过封禁、向不支持地区提供访问

封号规模看 Anthropic 透明度中心 7 月 23 日更新的数字：2026 年 1～6 月封了 1140 万个账号，收到 39.8 万次申诉，推翻 4.2 万次。2025 年下半年封号数是 145 万，半年涨到了将近 8 倍。

[图片]

申诉成功率大约十分之一。别指望靠它把号捞回来，当成最后一块补丁就好。

9 月新变化：不受支持地区可能被要求身份验证

Anthropic 9 月的威胁情报报告写明，账号疑似在中国、俄罗斯、伊朗等不受支持地区运行，或疑似转售，系统会要求身份验证，不通过就封。报告还点名了两类手法：用住宅代理加反检测浏览器批量注册的中转站，和冒充验证页面骗取证件的钓鱼网站。

被要求身份验证时，只能用本人的真实证件。用别人的证件、找人代过验证属于欺诈，后果比封号严重得多。这一关，环境配得再好也绕不过去，开始之前先想清楚。

2. 第一层：环境，固定比纯净重要

设备和出口 IP 固定下来，比花大钱买家宽有用。泄漏和跳节点比 IP 类型更常出事，天天在机场里切节点，IP 标签再漂亮也白搭。

2.1 动手前，先搞懂 5 个词

[图片]

打个比方：

机房 IP 像群租房的地址，一个门牌号后面挤着几千号人，快递员看一眼就知道这地方不对劲；

住宅 IP 像你自己家的门牌号，独门独户。平台风控就是那个快递员，IP 是它最先看的一样东西，但不是唯一一样，后面几层要补的就是其他信号。

[图片]

2.2 改时区：电脑和手机都改台北

Claude Code 会读系统时区和系统代理，这一点最早由 Asa（@app_sail）2026 年 7 月讲清楚，后来的中文教程大多沿用。

为什么选台北？台湾在官方支持名单里，Asia/Taipei 又和北京时间同属东八区，作息不用跟着改。新加坡也在名单里，社区却倾向避开，那边蒸馏和二手账号密度高，误伤的传闻也更多。

Mac

打开 系统设置 → 通用 → 日期与时间

关掉「使用你的当前位置自动设定时区」（旧版系统叫「自动设定时区」）

在时区里手动搜 Taipei / 台北

再去 系统设置 → 隐私与安全性 → 定位服务 → 系统服务（详细信息），关掉「设定时区」。很多人漏这一步，不关的话 Wi-Fi 定位会把时区拽回上海

打开「终端」，逐行粘贴检查：

[图片]

iPhone

设置 → 通用 → 日期与时间，关掉「自动设置」，时区选台北

设置 → 隐私与安全性 → 定位服务 → 系统服务，关掉「设定时区」

Windows：设置 → 时间和语言 → 日期和时间 → 关闭「自动设置时区」→ 选择 (UTC+08:00) 台北。

两端要对齐，电脑说自己在台北，手机说自己在上海，这本身就是一对矛盾信号。

2.3 选出口：先学会认机房 IP

这一步我自己踩过，之前用自建 VPS 加机场，Claude 动不动就降智，前一天还好好的，第二天回复突然变短，稍微复杂点的问题就给你回一段很敷衍的东西，GPT 也明显变慢。我一开始以为是模型在偷偷降级，后来随手查了一次 IP，ASN 类型那一栏，一眼 hosting。

买节点之前，先学会用 ipinfo.io 看 IP。

下图是 Google 的 8.8.8.8，AS Type 一栏写着 Hosting，这就是典型的机房 IP；你的出口这一栏应该显示 ISP 或 Residential。

[图片]

换成住宅 IP 以后我又查了一次，ISP 那一栏是美国一个真实的家庭宽带运营商名字，不再是 XXX Cloud、XXX Hosting 这种。看到这个结果，才算过了第一关。

也先说清楚适用边界：普通机场看视频、刷网页完全够用，没必要换。

你是重度 AI 用户，或者在 X 上认真做内容、不想被风控，IP 这一层才值得花钱。

社区常见的出口方案，按投入从低到高：

第三方测评小白研究所提醒，这家 Max 档分配的 IP 质量更好，Plus 和 Pro 是普通 IP。如果是养 Claude 主力号，我会建议直接上 Max 档，下单前在购买页确认是不是独享。共享是便宜，可共用的人里只要有谁去蒸馏、接第三方客户端，你都会被连坐。

买完按这个顺序做，别跳步：

注册账号，选套餐。地区选你准备长期用的国家，常用美国

后台复制订阅链接，导入 Clash Verge Rev（Mac / Windows）或 Shadowrocket（iPhone），具体步骤见 2.4

只留这一个节点，关掉「自动选择 / 按延迟自动切换」。延迟低不代表要轮询

去 ping0.cc 和 ippure.com 查：国家对不对、类型是不是家庭宽带 / ISP、共享人数多不多。看到 Hosting / 机房，先找客服换，别急着登 Claude

注册、登录、付款、日常使用，全程走这一条线路

IP 管的只是出口身份这一层。支付出问题、共享账号、把订阅接到 OpenClaw，换再干净的 IP 也照样封。

另外也有人碰到过个别节点漂到机房段，或者偶发故障，所以买完先查，不好用就换，别默认每个节点都能过 Claude。

想省钱、愿意折腾：IPRoyal 静态住宅 + 链式代理

开源教程 safe-claude 的作者推荐 IPRoyal：官网静态住宅 30 天约 2.7 美元 / IP 起（以官网实时价格为准），独享、不限流量、支持 SOCKS5，作者补充说它支持支付宝，24 小时内可以换 IP。代价是只给代理账号，得在 Clash 里把它挂在一个能出海的节点后面（链式代理），还要先过 KYC 审核。照着 safe-claude 的配置文件改，大约半小时。

自建 VPS：选独立主机商，避开国内大厂的海外区

VPS 是机房 IP，好处是出口只有你一个人用，2026 年社区横评（老唐）的结论：

搬瓦工 CN2 GIA：中文教程最多、支持支付宝、可以一键换 IP（约 8.79 美元 / 次），适合不想折腾的人。它的 IP 同一 C 段多人共用，先查再用

DMIT：同样是 CN2 GIA 线路，价格约为搬瓦工的一半

Vultr：按小时计费，删了重开就是新 IP；但没有中国优化线路，晚高峰丢包明显

阿里云国际、腾讯云海外、火山引擎海外都要避开：IP 显示在美国，hostname 和 ASN 却还带着国内大厂。

另外作息也别太假，你在国内白天高强度写代码，换到美西就是凌晨三四点。有人特意挂夏威夷，时差一倒，看起来更像熬夜的本地开发者。不过这条只影响画像，优先级排在固定出口后面。

2.4 装代理客户端，开 TUN 模式

社区和开发者常推荐的客户端：

[图片]

为什么一定要 TUN？Clash Verge Rev 官方文档的解释是，系统代理靠程序自觉遵守，程序可以不理；TUN 用虚拟网卡接管所有 TCP / UDP 流量，程序不用做任何配置。

[图片]

Clash Verge Rev 设置步骤：

导入订阅：「订阅」→ 粘贴订阅链接 → 导入，然后点选这个配置

先用系统代理跑通一次：打开「系统代理」，浏览器能打开 ipinfo.io，说明订阅没问题

「设置」→ 安装「服务模式」（会要求输入电脑密码）。这是不用管理员身份也能开 TUN 的前提

打开「TUN 模式」，然后关掉「系统代理」，避免两套代理叠在一起

「代理」页切到「全局」，选中你那个固定节点。用 Claude 期间不建议用规则模式，分流规则写错就会漏

新开一个终端窗口，再做下面的自检（老窗口可能还带着旧的代理变量）

Surge 用户：打开「增强模式」，系统代理保持关闭，效果相同。

2.5 登录 Claude 前的 5 项自检

每次换节点、重装系统、换电脑之后，都完整做一遍。任何一项不过，先别登录。

[图片]

我管这一步叫 IP 洗脸：洗之前照照镜子，看看自己有多脏；洗完再照一次，确认真的干净了。听起来有点蠢，但真的有用。

① 查出口 IP。浏览器打开 ipinfo.io / ping0.cc / whoer.net，或在终端运行：

[图片]

看 country、city、org：国家固定，城市别每次变，org 不是一眼能认出的机房。ippure.com 可以再看纯净度，社区检测页 ip.net.coffee/claude 只作参考。

② 查 WebRTC 泄漏。打开 browserleaks.com/webrtc，页面里不能出现你的国内真实 IP。开了 TUN 一般不会漏；还漏的话，Chrome 装 Google 官方扩展 WebRTC Network Limiter，选「Use my proxy server (if present)」；Firefox 在 about:config 里把 media.peerconnection.enabled 改成 false。

③ 查 DNS 泄漏。打开 browserleaks.com/dns，结果里不应出现中国的 DNS 服务器。TUN 模式默认会接管 DNS；仍然看到国内 DNS，就检查 Clash 配置里 DNS 是否开启、dns-hijack 是否生效。

④ 查系统代理残留（Mac 很关键）：

[图片]

⑤ 清掉终端里的代理和中转残留：

[图片]

重点看有没有 ANTHROPICBASEURL。用过镜像站、Claude Code Router 或各种中转的，这里常有残留，服务端一看请求就知道你没走官方。找到就删掉那一行，再新开终端。

可选加固：关闭 IPv6。不少代理配置只接管 IPv4，IPv6 可能直连漏出去。Mac 上运行 networksetup -setv6off Wi-Fi（用网线就把 Wi-Fi 换成 Ethernet）；以后想恢复，运行 networksetup -setv6automatic Wi-Fi。

2.6 设备：一号一环境

同一台设备登多个账号，是国庆这轮最扎眼的特征，所以设备这一层，至少做到这几条：

[图片]

一个号、一个人、一台常用电脑，哪怕同事只想先用用，也别借

浏览器单独建一个资料（Chrome 右上角头像 → 添加），只用来登 Claude。单号用不着指纹浏览器，那是多账号工作室的工具，条款禁止的恰恰是多账号规避

Claude Code 登录时运行 BROWSER=false claude，把它给出的授权链接复制到这个专用浏览器里打开，免得默认浏览器带着别的环境去授权

定期去 claude.ai → Settings → Account → Active sessions，陌生登录点 ⋮ → Terminate 踢掉

手机端能不用就不用，社区复盘里有人只在电脑上用 Claude，手机换别的模型，减少设备分叉

被封过、要换新环境时，先清本机残留，常漏的有三处：用户目录下的 \~/.claude，macOS 钥匙串里的「Claude Code-credentials」（只删文件夹不够），应用支持目录里的历史会话。动手前先备份 \~/.claude，你的 Skills、Hooks 和会话都在里面。

清理可以用开源脚本 claude-cleanup：先完整备份，只把文件移进带时间戳的废纸篓目录，skills、hooks、项目会话都在保护名单里。用 Codex 或普通终端运行，别让正在运行的 Claude Code 清理它自己。

条款写得很明白，用新号绕过封禁本身就是违规，清残留是为了少被连坐，不是给开新号铺路。

[图片]

3. 第二层：账号和支付，账单信用常常比 IP 更重

3.1 邮箱和手机号

用你自己能长期控制的 Gmail / Outlook / Proton，别用一次性邮箱

别买二手谷歌邮箱，它可能已经和一批被封的号绑过。老 Gmail 更稳的说法也没有公开依据，谷歌不会把账号年龄告诉 Anthropic

手机号：国内号、接码平台号，社区反馈是能过注册，但后续容易被标记。有条件就用你能长期控制的支持地区号码

验证邮件要在同一个代理环境、同一个专用浏览器里点开，环境配得再干净，在日常浏览器里点一下 Claude 的登录链接，真实 IP 就交出去了。注册阶段翻车最多的，就是这一步。

[图片]

3.2 订阅节奏：按周走，别一天登顶

新号加新卡直接开 Max 20x，是风控里最显眼的一类。社区观察到的窗口大致在注册或充值后 24～72 小时，也有人把第一次续费看成第二道门。可以按这个节奏走：

[图片]

额度进度条变黄就停。这条经验来自被封过多个号的人，做起来一分钱不花。

3.3 付款渠道：决定号没了你亏多少

官方退款说明第一句就写着，除条款明确规定或法律要求外，所有付款不退。所以付款这一步，先别急着问哪张卡能刷过，先想清楚号没了，钱找谁退。

[图片]

社区对支付方式的排序是：支持地区实体信用卡 > 有门槛的正规卡 > 礼品卡内购 > 无门槛虚拟卡。账单地址、卡发行国、出口 IP、系统时区，尽量落在同一个国家。

第一次开会员，能走 App Store 就走 App Store。贵是贵一点，号没了至少还能找苹果退款：

准备一个能正常付款的 Apple ID（社区常用美区 ID + 官方礼品卡，账单国家和出口尽量一致）

iPhone 下载官方 Claude App，用同一个 Anthropic 账号登录

在 App 里升级到 Pro / Max，走苹果内购，不要跳回网页绑卡

订阅成功后，电脑端用同一账号登录

Gorden Sun 补过一句：同一个苹果账号第一次被封申请退款往往有戏，再封就不一定了，别把退款当成稳定现金流。

3.4 隐私开关

打开 claude.ai/settings/data-privacy-controls，按你的意愿关掉帮助改进 Claude 的开关。官方文档写明，关掉后会话保留 30 天，开着是 5 年。它防不了封号，只是少交一份样本；被安全分类器判定违规的对话，仍可能进入安全审查。
