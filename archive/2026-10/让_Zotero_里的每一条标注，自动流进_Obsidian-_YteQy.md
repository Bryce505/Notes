Zotero 里划过的每一条高亮，都会在 Obsidian 里等你

先问个问题。你在 Zotero 里读过的那些 PDF，划的高亮、写的批注，后来用上了多少？

我问过身边十几个研究生，答案高度一致。读的时候觉得每句都重要，高亮刷得满页都是，等真坐下来写综述，脑子里只剩一个模糊的印象，那句话在哪篇、第几页、当时为什么划的，全没了。

问题不在记性，在于标注和思考分家了。标注躺在 Zotero 的 PDF 里，想法无处安放。这一期，我们把这两个地方接通，让标注自动带着页码、颜色和你的批注，流进 Obsidian 的文献笔记。一次配置，受益到毕业。

01

记住最后一行。Obsidian 里的文献笔记不是你手敲的，是插件生成的，每次重新导入都会刷新。你只在固定区域写自己的东西，互不覆盖。

02

整条数据流，长这样

Zotero 读 PDF → 高亮＋批注 → Zotero Integration → Obsidian 文献笔记

桥梁插件的名字就叫 Zotero Integration，社区插件榜常年前排

生成出来的笔记里，标题、作者、年份、DOI、摘要全部自动填好，你划过的高亮按颜色分类排好，每条都带着页码，点一下跳回 PDF 原页。你要做的只有一件事，在笔记顶部回答三个问题。

03

装三样东西，花二十分钟

① Zotero 7 ，zotero.org 免费下载。现在的版本内置 PDF 阅读器，高亮批注不用再装旧版的插件。 ② Better BibTeX ，装在 Zotero 里的插件。它负责给每篇文献生成一个终身不变的身份证，叫 citekey。 ③ Zotero Integration ，装在 Obsidian 里的社区插件，负责两边通话。

重点说 citekey。装好 Better BibTeX 后，在它的设置里把引用键规则设成 auth.lower + year + shorttitle(3,3) ，意思是第一作者姓小写、年份、标题前三个字母。

smith + 2025 + kno 作者姓　　　年份　　　标题前三字母 @smith2025kno

这个键就是文献在两个软件之间的接头暗号。第 2 期说的文献笔记文件名、第 5 期写论文时的引文，用的都是它。它一旦生成不要手改，改了两边就对不上了。

04

插件设置，照着点五步

在 Obsidian 装好 Zotero Integration 后，打开它的设置页，只需要定五件事。

第一步 ，General 里指定 Zotero 的数据接口，Zotero 开着它就能自动连上。

第二步 ，PDF 附件文件夹指向 Zotero 的存储目录，这样笔记里的页码链接才能打开原 PDF。

第三步 ，文献笔记的存放位置选 02-Literature，也就是第 2 期建好的文件夹。

第四步 ，笔记命名填 @{{citekey}} ，生成的文件就是 @smith2025kno.md。

第五步 ，导入模板选一个 Markdown 模板文件，模板长什么样，下一节直接给你。

设完之后，用法简单到离谱。命令面板搜「Zotero Integration: Import literature note」，回车，在弹出的列表里选一篇，笔记就生成好了。以后这篇有了新标注，再导一次，自动更新。

05

模板逐行看，不用背，拿去改

模板用的是 Nunjucks 语法，看着像代码，其实就是填空指令。下面这个精简版足够用，存成 Templates 里的「文献笔记.md」，在插件第五步选中它。

--- type : literature-note citekey : {{citekey}} year : {{date | format("YYYY")}} status : reading --- # {{title}} ({{date | format("YYYY")}}) > {{abstractNote}} ## 三个问题 - 解决了什么问题： - 用了什么方法： - 我能用它干什么： ## 标注 {% persist "notes" %} {% for entry in annotations %} > {{entry.annotatedText}} {{entry.comment}}　p.{{entry.page}} {% endfor %} {% endpersist %}

两个地方值得注意。三个问题下面是你的自留地，写什么都不会被刷新。标注区域被 persist 包起来，意思是重新导入时，你在每条标注后面补的想法会保留，不会被覆盖。

高亮是原料，批注才是产品。光划不写，等于没读。

我的习惯是，读的时候只做两件事：划关键句，在真正有想法的那条标注上写一句批注，哪怕只有「这个方法可以用到实验三」。导出后，这些批注就是未来综述的现成砖块。

06

给高亮立规矩：四种颜色，四种命运

新手的高亮是没有差别的，满页一个颜色，等于没标。给自己定一套颜色约定，模板里可以按颜色分组导出，我用的是这一套。

🟡 黄色 · 核心论点 作者最想让你记住的结论，一篇不超过五条 🔵 蓝色 · 方法数据 样本、模型、关键数字，写方法部分时回来抄 🔴 红色 · 存疑质疑 觉得不严谨、想反驳的点，组会讨论的弹药 🟢 绿色 · 为我所用 能直接用进自己课题的，必须配一句批注

模板里加一句按颜色判断的循环，就能让导出的标注自动按这四类归堆。写法是在 for 循环里加 if 判断 entry.color，网上搜「Zotero Integration color template」有现成片段，建议先用上面的朴素版跑顺，再追求这个。

07

论文之外，用 Web Clipper 接住网页

科研读的不全是 PDF。预印本网页、政府统计数据、课题组主页、一篇还没正式发表的工作论文，这些以前要么截图要么链接收藏，然后再也没打开过。

Obsidian 官方出的 Web Clipper 是个浏览器扩展，装在 Chrome 或 Edge 里。看到值得存的页面，点一下图标，它会把正文抓成 Markdown 存进库，还能按模板自动加标签、塞进 Inbox。2025 年后的版本甚至支持用自然语言告诉它要抓页面的哪部分。

这样一来，正式论文走 Zotero，其他一切走 Clipper，入口统一进 Inbox，你的库再没有流落外头的材料。

08

今晚跑通最小闭环

① 装好 Zotero 7 和 Better BibTeX，确认一篇文献有了 citekey。 ② Obsidian 装 Zotero Integration，按五步设好路径。 ③ 用上面的模板导入一篇你正在读的论文。 ④ 认真回答那三个问题，只准用三句话。

这套流程跑通的那一刻，感觉是很明显的。你第一次拥有了一篇「活的」文献笔记，原文在 Zotero，思考在 Obsidian，中间没有任何复制粘贴。

读一篇有一篇的落点，读两百篇就有两百块编好号的砖。

下一期，我们不再让砖平摊在地上。用双链、MOC 和 Canvas，把它们织成一张能长出综述的网。
