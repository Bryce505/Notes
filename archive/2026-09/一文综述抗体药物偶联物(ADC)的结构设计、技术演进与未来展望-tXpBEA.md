01

引言

恶性肿瘤仍然是全球主要的健康负担，尽管手术、放疗、化疗、靶向治疗和免疫治疗取得了进展，但许多癌症的发病率和死亡率仍在持续上升。根据 GLOBOCAN 统计， 2018 年癌症导致全球近 1000 万人死亡 ，并持续对公共健康构成严重威胁。传统的化疗药物虽然通常具有很强的效力，但存在固有的局限性，如 肿瘤选择性差、全身毒性和剂量限制性不良反应 。这些缺点严重限制了它们的临床应用，并常常导致次优的治疗效果，尤其是在转移性或难治性癌症中。随着分子肿瘤学、精准医学和抗体工程的快速发展，研究人员越来越多地寻求设计兼具高选择性和强效细胞毒性的治疗策略。在这些新兴疗法中， 抗体药物偶联物 ( ADCs ) 已成为最有前景的靶向抗癌药物类别之一 。 ADCs 在概念上植根于保罗 · 埃尔利希一个多世纪前提出的 “ 魔法子弹 ” 理论，通过识别肿瘤相关抗原的单克隆抗体，将细胞毒性有效载荷直接递送至肿瘤细胞，从而实现精确的肿瘤杀伤，同时保护健康组织。

自首个 ADC 药物 吉妥珠单抗奥唑米星 ( Mylotarg ) 于 2000 年获批用于治疗急性髓系白血病以来， ADC 技术经历了显著的发展和变革。 早期 ADCs 受限于使用鼠源抗体、不稳定的连接子和效力不足的细胞毒性药物 ，导致不可预测的药代动力学、脱靶毒性和有限的治疗活性。然而，随后在 抗体人源化、连接子化学和超强效有效载荷开发 方面的进展，显著提高了 ADCs 的稳定性、特异性和疗效。在过去十年中， ADCs 迅速发展成为肿瘤学领域的主要治疗类别， 截至 2024 年，全球已有 16 个 ADCs 获批，超过 425 个候选药物正在临床开发中 。这些药物在血液系统恶性肿瘤和越来越多的实体瘤 ( 包括 乳腺癌、卵巢癌、尿路上皮癌、非小细胞肺癌和宫颈癌 ) 中显示出显著的临床获益。代表性 ADCs 如 恩诺单抗维多汀 ( Padcev ) 、德曲妥珠单抗 ( Enhertu ) 和戈沙妥珠单抗 ( Trodelvy ) 的成功，重塑了治疗范式，并为治疗选择有限的患者扩大了治疗前景。

ADC 领域的快速扩张源于其固有的多学科性质。 ADC 的设计需要 错综复杂地整合抗体生物学、药物化学、生物偶联策略、细胞运输机制、药代动力学模型和可生产性考虑 。抗体组分决定抗原特异性、内化行为和 Fc 介导的免疫效应功能。 连接子控制全身稳定性和细胞内有效载荷释放 ，平衡循环稳定性与有效药物释放之间的矛盾需求。 有效载荷通常比传统化疗药物强 100-1000 倍 ，其结构必须与偶联相容，并能发挥持久的细胞内细胞毒性。同时， 生物偶联方法和由此产生的药物抗体比 ( DAR ) 深刻影响 ADC 的药代动力学、聚集倾向和治疗指数 。即使是细微的结构修饰 —— 例如单个连接子替换或偶联位点的改变 —— 也可能在体内剧烈改变 ADC 的行为。因此， ADC 开发必须将分子视为一个集成系统，而非三个模块化组件的简单组合 。

尽管取得了显著进展，但 ADC 的临床转化仍面临挑战。 肿瘤抗原异质性 可能限制 ADC 的治疗范围，并导致原发性或获得性耐药。 脱靶毒性 仍然是一个主要问题，特别是对于具有不稳定连接子或高膜渗透性有效载荷的 ADCs ，它们可能引起全身性不良反应，如 肝毒性、骨髓抑制或神经病变 。 细胞内运输的复杂性 ，涉及不同的内吞途径和可变的溶酶体活性，影响有效载荷释放效率和治疗效力。此外，许多肿瘤细胞上调 外排转运蛋白 ( 如 P- 糖蛋白 ) ，减少细胞内有效载荷的积累。 生产具有精确 DAR 控制和足够稳定性的高质量 ADCs 也仍然具有挑战性，特别是对于位点特异性偶联技术。这些局限性推动了 下一代 ADCs 的开发，其特征包括改进的抗原选择策略、 双特异性或双互补位抗体形式 、对 肿瘤特异性刺激 ( 如蛋白酶、酸性 pH 或 ROS ) 响应的可裂解连接子，以及全新类别的细胞毒性药物，包括 RNA 剪接抑制剂、 Bcl-xL 抑制剂和 NAMPT 抑制剂 。

随着 ADC 技术的不断成熟，其临床影响正在迅速扩大。一些新一代 ADCs 不仅显示出强效的细胞毒性活性，还具有调节抗肿瘤免疫的能力，包括 诱导免疫原性细胞死亡 和与 免疫检查点抑制剂 的协同作用。值得注意的是， 德曲妥珠单抗在 HER2 低表达肿瘤中显示出显著获益 ，挑战了长期存在的生物标志物定义，并拓宽了靶向治疗的范围。此外，胞外 可裂解连接子和具有强旁观者效应的有效载荷 在治疗内化能力低或具有显著瘤内异质性的肿瘤方面显示出前景。这些进展表明， ADCs 正朝着高度工程化的 “ 精准药物递送系统 ” 转变 ，能够在多个层面上利用肿瘤生物学。

鉴于 ADC 领域的复杂性和快速演变，有必要进行一篇重点综述，以综合指导临床相关进展的关键设计原则。本综述不试图详尽地编录每个报道的 ADC ，而是 重点介绍具有代表性和影响力的实例 ，讨论 ADCs 的结构基础、作用机制、技术演进、临床验证和新兴靶点、连接子化学、有效载荷类别以及持续存在的挑战。通过强调 抗体形式、连接子设计和有效载荷特性 之间的关系，本文旨在支持合理开发具有改善疗效、安全性和转化潜力的下一代 ADCs 。

02

ADC 的作用机制

静脉给药后， ADC 进入体循环并分布于全身， 得益于单克隆抗体组分的高特异性 ， ADC 选择性地识别并结合肿瘤细胞表面过表达的同源抗原，形成稳定的抗原 -ADC 复合物，该复合物随后通过 受体介导的内吞作用 被内化。内化后，可能出现几种细胞内命运：

(i) FcRn 介导的再循环 — 部分内化的 ADC- 抗原复合物在内体区室与 新生儿 Fc 受体 ( FcRn ) 相互作用。这些复合物可被再循环回细胞表面并释放到循环中，代表了一种生理 “ 缓冲 ” 过程，可能部分减轻正常细胞的脱靶摄取。

(ii) 溶酶体运输和有效载荷释放 — 剩余的 ADC- 抗原复合物被运输至溶酶体。在这个富含蛋白酶且通常呈酸性的环境中， 抗体骨架被降解和 / 或连接子被裂解 。对于 不可裂解连接子 ，溶酶体蛋白酶消化抗体以释放活性的药物 - 氨基酸加合物。对于 可裂解连接子 ，化学或酶促触发因素 ( 例如，酸性 pH 、氧化还原电位、溶酶体蛋白酶和糖苷酶 ) 促进连接子断裂，导致活性细胞毒性有效载荷的释放。释放的有效载荷随后通过干扰基本的细胞过程 ( 如 微管动力学、 DNA 复制和修复、拓扑异构酶功能或转录 ) 来发挥其药理作用，这最终导致 细胞周期停滞和凋亡 ( 图 1 ) 。根据释放物种的膜渗透性不同，某些 ADC 还可以诱导 “ 旁观者效应 ” ，即释放的有效载荷扩散到邻近的抗原低表达或抗原阴性肿瘤细胞中。

03

ADC 技术的演进

第一代 ADC 主要采用 鼠源单克隆抗体 ，辉瑞的 Mylotarg ( 吉妥珠单抗奥唑米星 ) 是治疗 CD33 阳性急性髓系白血病 ( AML ) 的代表性例子。然而，由于严重的安全问题 ( 包括严重毒性 ) ， Mylotarg 最终于 2010 年退市。该药物后来于 2017 年重新获批，包括与化疗联合，用于治疗 AML 。另一个例子是 BR96- 多柔比星，它通过不可裂解连接子将传统化疗药物多柔比星偶联到鼠源抗体上。总体而言，这些早期 ADC 并未显示出相对于相应游离细胞毒性药物的优越疗效 。此外，发现它们的连接子化学在体循环中发生缓慢水解，导致不受控的有效载荷释放和意外的脱靶毒性。 第一代 ADC 的局限性催生了第二代 ADC 的发展 ，其在抗体工程、连接子稳定性和有效载荷设计方面有所改进。

目前， 大多数已上市的 ADC 被认为是第二代产品 ，代表性例子包括用于治疗复发性霍奇金淋巴瘤和系统性间变性大细胞淋巴瘤的 维布妥昔单抗 、用于 HER2 阳性转移性乳腺癌的 恩美曲妥珠单抗 ( T-DM1 ) ，以及用于急性髓系白血病的吉妥珠单抗奥唑米星。此外， 奥英妥珠单抗 和最近获批的用于 B 细胞恶性肿瘤的 维泊妥珠单抗 被设计为强效抗癌药物，能够将高细胞毒性有效载荷肿瘤选择性地递送，同时保护健康组织。通过将这些超强效细胞毒性药物偶联到肿瘤特异性抗体上，其致命活性可以集中在表达抗原的肿瘤细胞内。此外，抗体偶联可以改善小分子有效载荷的药代动力学行为，有效地赋予其类似免疫球蛋白的延长半衰期，相对于未偶联的药物。尽管有这些进展， 第二代 ADC 仍面临重要限制 ，包括脱靶毒性、过早清除 ( 在某些情况下 ) ，以及与未偶联抗体竞争抗原结合和肿瘤渗透。

从早期 ADC 世代中吸取的教训加速了 第三代 ADC 的发展，其主要创新集中在 偶联化学和药物载量控制 。特别是， 位点特异性偶联 能够生产具有确定和均一药物抗体比 ( DAR )( 最常见的是 DAR 2 或 DAR 4 ) 的 ADC ，从而 提高产品一致性、减少脱靶毒性并增强药代动力学性能 。与此同时，对 新型 ADC 靶点和下一代有效载荷类别 的持续探索进一步扩大了治疗机会并提高了抗肿瘤疗效。

除了有效载荷效力和连接子稳定性的改进之外， 偶联化学的进步也已成为现代 ADC 开发的一个决定性特征 。随着 ADC 设计的成熟，越来越明显的是，连接子化学不能与偶联化学孤立地考虑。在早期 ADC 中，有效载荷通常通过 随机偶联 方式安装到溶剂可及的赖氨酸残基或部分还原链间二硫键后暴露的半胱氨酸上。这些方法在实验上简单直接，在某些情况下仍然可用。然而，它们的局限性是固有的：它们生成 不仅 DAR 不同，而且在抗体表面有效载荷位置分布也不同的混合物 。这种 异质性不仅仅是一个生产上的不便 。一系列有影响力的研究表明， 偶联位点可以显著影响疏水性、聚集倾向、去偶联动力学、血浆暴露量，并最终影响治疗指数 。换句话说， 连接位点本身是一个设计变量 ，而不是合成可达性的被动结果。

这一认识推动了 位点特异性偶联策略 的发展。最早展示明确转化价值的方法之一是 工程化半胱氨酸平台 ，以 THIOMAB 型构建体为代表，其引入了预定义的含硫醇位点，从而能够制备具有更严格 DAR 分布和改善体内性能的 ADCs 。后续工作提出了同样重要的观点： 并非所有工程化位点表现都相同 。即使使用相同的连接子 - 有效载荷， 局部微环境、溶剂可及性以及马来酰亚胺键对交换或水解的敏感性 也可能导致稳定性和药代动力学的显著差异。这些研究将该领域从纯粹的化学计量学观点转向了更具结构性的观点，其中 DAR 控制和位点选择被协同优化。

此后，更广泛的正交技术扩展了位点选择性 ADC 组装的范围。 基因编码的非天然氨基酸 提供独特的反应性手柄，并允许精确控制位点和化学计量。 酶介导的方法 ，包括基于 微生物转谷氨酰胺酶 和 分选酶 的偶联，在相对温和的条件下提供了高效制备均一构建体的途径。总的来说，这些方法之所以有价值，不仅是因为它们本身能产生分析上更纯净的材料，而是因为它们允许 协调地调整偶联位点、连接子稳定性和有效载荷特性 。因此，在当前的 ADC 开发中， 连接子化学最好被视为分子设计的核心组成部分 ，与可开发性、药理学和安全性密切相关，而非下游的技术改进。

04

抗体靶点

ADCs 的抗体组分主要负责 靶点识别 ，并能触发靶抗原依赖性的肿瘤细胞表面内化。在可用的抗体形式中， 人源化免疫球蛋白 G ( IgG ) 因其相对较低的免疫原性和良好的可开发性，是 ADCs 中最广泛使用的。 IgG 包含四个亚类 ( IgG1 、 IgG2 、 IgG3 和 IgG4 ) 。值得注意的是，在目前获批的 ADCs 中，只有极少数使用 IgG4 作为抗体支架，而 绝大多数使用 IgG1 。这种偏好很大程度上归因于 IgG1 优越的体内稳定性、更长的血清半衰期 ，以及其对 Fcγ 受体 ( FcγRs ) 的更高亲和力，这有助于更有效地参与先天免疫效应细胞，如 自然杀伤 ( NK ) 细胞和巨噬细胞 。

然而，在 ADC 设计中， 保留完整的 Fc 介导的效应功能并非总是可取的 。对于许多 ADCs ，主要治疗目标是选择性细胞内递送有效载荷，而非以裸抗体预期的方式募集免疫效应功能。在这种情况下， Fc 与 Fcγ 受体或 C1q 的结合可能是把双刃剑 。一方面，此类相互作用可能支持免疫细胞参与；另一方面，它们可能 改变生物分布、促进 FcγR 阳性髓系细胞群的摄取，或增加非生产性清除 。这些考虑对于携带 高效价或膜渗透性有效载荷 的 ADCs 尤其相关，因为即使是有限的靶点非依赖性处理也可能产生毒理学后果。

这就是对 Fc 工程化或 Fc 沉默抗体 兴趣日益增长的理由。已报道了一系列 Fc 沉默解决方案，包括 LALA 型、 LALE 型 和其他旨在减弱 Fcγ 受体和 / 或补体结合，同时保留抗原识别的变体。最近更多的比较工作也强调， Fc 沉默不应仅通过效应功能的丧失来判断；可开发性同样重要 。一些变体显示出更有利的稳定性、可制造性和整体生物物理行为，这表明 Fc 沉默不是单一的统一设计选择，而是必须谨慎选择的一系列相关工程解决方案。从 ADC 的角度来看，当抗体主要用作递送载体而不是作为本身具有效应功能的治疗剂时，这些格式尤其具有吸引力。

与此同时， Fc 沉默不应该被认为是一个普遍优越的设计规则。临床前研究表明，在一些肿瘤相关巨噬细胞丰富的环境中， Fc- Fc γ R 相互作用可能有助于肿瘤内 ADC 加工，并可以增强抗肿瘤活性。相反，其他研究表明，依赖 FcγR 的 ADC 聚集物内化可以增强表达 FcγR 的细胞的脱靶细胞毒性，而 Fc 沉默可以减轻这种毒性。因此，文献支持一种适合 ADC 开发的 Fc 工程观点。 完整的 IgG1 效应功能、减弱的 Fc 参与和深度沉默的 Fc 变体都应该被视为上下文相关的选项，根据靶标生物学、肿瘤微环境、有效载荷类别和安全优先级进行选择，而不是默认的惯例。

理想的 ADC 抗体应该结合具有高特异性的肿瘤选择性抗原， 理想的抗原是在肿瘤细胞上唯一表达而在正常组织上不存在 ( 或表达水平可忽略不计 ) ，以最大限度地靶向肿瘤，同时最小化靶内 / 非肿瘤毒性 。

截至 2025 年 10 月， 16 种上市 ADC 涵盖 11 个不同的靶点 ( 表 1) ，包括 CD33 、 CD30 、 HER2 、 CD22 、 CD79b 、 Nectin-4 、 BCMA 、 EGFR 、 CD19 、组织因子 (TF) 和叶酸受体 - α (FR α ) 。在目前正在开发的大约 425 个 ADC 候选药物中，最受关注的靶点包括 HER2 、 EGFR 、 CLDN18.2 、 Trop-2 、 c-MET 、 CD19 、 PSMA 、 MUC1 、 BCMA 和 PD-L1 。其中许多是具有大量临床验证的既定靶点，而其他靶点仍处于积极的临床研究中。此外，一些项目正在推进双特异性或多特异性格式，如 HER2 双特异性抗体、 PD-L1/PD-L2 双特异性抗体和 CLDN9/CLDN6 双特异性抗体。

血液恶性肿瘤的典型特征是谱系相关表面标志物的异常过表达，包括 CD19 、 CD20 、 CD22 、 CD33 、 BCMA 和 CD79 。

· CD19 是 B 细胞谱系的典型标记物，在从早期 ( 前 )B 细胞阶段到分化的大部分 B 细胞个体发育过程中表达，也可在滤泡树突状细胞中检测到。作为 B 细胞受体 (BCR) 信号复合体的关键共受体， CD19 已被确立为 B 细胞非霍奇金淋巴瘤 ( B-NHL ) 和 B 细胞白血病的中枢治疗靶点。

· CD20 主要定位于初始和成熟 B 淋巴细胞表面，在向浆细胞终末分化过程中丢失；其在 B 细胞淋巴瘤中的频繁高表达使其成为疾病干预的重要靶点。

· CD22 主要作为 BCR 信号转导的负调节因子，并参与 B 细胞运输和外周 B 细胞免疫耐受的维持。它在正常 B 细胞上广泛表达，也存在于 B- 急性淋巴细胞白血病 ( B-ALL ) 的分化 B 细胞群体以及大多数 B-ALL 祖细胞上。

· CD33 显示髓系祖细胞限制性表达模式，其表达通常在成熟过程中下降；然而，它在急性髓系白血病 ( AML ) 白血病母细胞和部分 ALL 相关细胞亚群上的持续表达，支持其作为血液肿瘤靶向治疗的关键标志物和靶点的实用性。

· BCMA ( B 细胞成熟抗原 ) 是肿瘤坏死因子受体 ( TNFR ) 超家族的一员，通过配体依赖性信号传导调节骨髓中浆母细胞和浆细胞的存活。该轴在多发性骨髓瘤的恶性增殖中也起着关键作用，使 BCMA 成为一个特别有吸引力的治疗靶点 。

· CD79 是由 CD79a 和 CD79b 组成的异二聚体，是 BCR 信号复合体的必需组分；值得注意的是， CD79b 选择性表达于 B 细胞 ，并在某些 B 细胞淋巴瘤细胞 ( 包括伯基特淋巴瘤和其他 B-NHL 亚型 ) 表面富集，支持其作为精准治疗的高价值靶点。

在实体瘤中，治疗性抗体最常靶向恶性细胞表面异常过表达的受体分子，如 HER2 、 TROP2 、 Nectin-4 、 FRα 和组织因子 ( TF ) 。

· HER2 ( 人表皮生长因子受体 2 ) 在多种恶性肿瘤的质膜上频繁上调，包括 胆道癌、结直肠癌、非小细胞肺癌 ( NSCLC ) 、膀胱癌和乳腺癌 。在乳腺癌中，大约 10−20% 的病例表现出 HER2 过表达，这可以直接增强肿瘤细胞增殖和存活。重要的是， HER2 并非唯一肿瘤限制性 ，它也在正常上皮组织和心肌细胞的膜上生理性表达，这一特征可能导致与 HER2 靶向治疗相关的心脏毒性。

· TROP2 是一种细胞表面糖蛋白，其在实体瘤中的失调表达使其成为精准治疗的有吸引力的靶点。虽然 TROP2 在若干健康组织的上皮区室中显示出生理表达，包括 皮肤、宫颈上皮、扁桃体和胸腺 ，但它也在多种上皮源性癌症中表达，如 乳腺癌、胰腺癌、尿路上皮癌和卵巢癌 。在与促进存活和增殖的生长因子结合后， TROP2 可以启动下游信号级联反应，调节关键的致癌行为。

· Nectin-4 是一种 I 型跨膜蛋白，属于 Nectin 免疫球蛋白样粘附分子家族，主要介导钙非依赖性细胞 - 细胞粘附并参与细胞骨架重塑。 Nectin-4 在正常组织中表达通常较低，而其显著上调是多种上皮恶性肿瘤的特征性分子特征。

· 叶酸受体 -α ( FRα ) 是一种膜结合受体，对叶酸和几种叶酸衍生物具有高亲和力，常在卵巢癌、肺癌和乳腺癌细胞表面过表达。除了介导叶酸内化外， FRα 相关的运输已被牵涉到促生长通路的转录调控中；值得注意的是， 叶酸运输对 DNA 生物合成至关重要 ，为 FRα 靶向策略提供了理论基础。

· 组织因子 (TF) ，也称为凝血因子 III 或 CD142 ，是一种促凝剂跨膜糖蛋白，与 VIIa 因子形成复合物，可触发细胞内信号传导。生理条件下， TF 在单核细胞、血小板和上皮细胞表面表达。相反， TF 在一系列恶性肿瘤中异常上调，包括胶质母细胞瘤、乳腺癌、结直肠癌、胰腺癌、肺癌和宫颈癌，在这些肿瘤中，它已成为一个与治疗相关的重要分子特征。

在基于抗体的靶向治疗中，程序性细胞死亡蛋白 1 (PD-1) 及其配体 PD-L1 是最完善的免疫检查点生物标志物和治疗靶点。与大多数主要作用于肿瘤内在信号通路的常规靶向药物不同， PD-1/PD-L1 轴抑制剂表现出双重靶向特征：它们可以直接作用于表达 PD-L1 的肿瘤细胞，同时通过阻断抑制信号调节免疫细胞功能，从而缓解免疫抑制并恢复细胞毒性效应活性。

目前， ADC 的临床试验继续扩展到新的靶标空间，正在进行的项目针对新出现的肿瘤相关抗原，如 CLDN6 (CLDN6) 、δ样配体 3 (DLL3) 、间皮素 (MSLN) 、锌转运蛋白 LIV-1 (SLC39A6) 和 B7 同源物 4 (B7-H4) 等。

05

连接子

理想的连接子应具有强大的循环稳定性，以防止有效载荷在血液中过早释放，同时一旦偶联物到达其预定的作用位点，仍然能够控制有效载荷的释放 。嵌入在链接器中的释放触发机制在很大程度上决定了有效载荷释放是否“刺激响应”。对于可切割的连接子，特定的化学触发器被设计为在暴露于定义的生物刺激 ( 如溶酶体酶、酸性 pH 或氧化还原条件 ) 时启动有效载荷释放。相比之下，不可切割的连接子缺乏这样的触发器，其功能主要是作为稳定的共价栓，将有效载荷固定在抗体上。因此，连接子通常分为两大类： 不可切割的和可切割的连接子 。

5.1. 不可裂解连接子

硫醚基团

含有不可切割连接体的 ADC 通常依赖于细胞内化来获得活性，因为只有在抗体成分在溶酶体内进行蛋白水解降解后，有效载荷才会释放。在 ADC 的发展过程中，已经建立了多种不可切割的连接物化学，其中 n- 琥珀酰亚胺基 4-(N- 马来酰亚胺甲基 ) 环己烷 -1- 羧酸盐 (SMCC) 是一个典型的例子 ( 图 2) 。已上市的 ADC Kadcyla (ado- 曲妥珠单抗 emtansine ； T-DM1) 采用 SMCC 衍生的硫醚连锁，在体循环中具有优异的稳定性。与早期的可切割连接器设计相比，这种结构减少了过早有效载荷释放，从而降低了脱靶毒性。此外，基于 smcc 的连接器结构简单，支持可控制造，特别适合与类美坦素有效载荷 ( 例如 DM1/DM4) 接合。

[图片]

图 2. ADC 结构中不可切割硫醚连接器 SMCC 的结构。

在细胞内加工和分解代谢后，带有 SMCC 型不可裂解连接子 的 ADC 主要产生 Lys-SMCC-DM1 作为特征性的肿瘤相关分解代谢物。值得注意的是，由于这种释放的分解代谢物 膜渗透性有限 ，基于不可裂解连接子设计的 ADCs 通常 表现出最小的旁观者杀伤效应 ，因为活性物种不易扩散到邻近的抗原阴性细胞中。

5.2. 可裂解连接子

可裂解连接子可根据其有效载荷释放机制进一步分为两大类： 酶依赖性连接子 和 化学触发连接子 。在这两种情况下，释放由裂解位点的物理化学特性和相关的生物环境 ( 最常见的是溶酶体区室和 / 或肿瘤微环境 ) 决定。

5.2.1. 化学触发连接子

二硫键连接子

含二硫键的连接子可通过 硫醇介导的亲核攻击 发生裂解，导致活性有效载荷的释放。虽然还原型人血清白蛋白 ( HSA ) 构成血浆中最丰富的硫醇物种，但其对大分子二硫化物的反应性相对有限。相比之下，细胞溶质含有高浓度的 谷胱甘肽 ( GSH ) ，一种含硫醇的三肽，对二硫键具有显著更强的亲核反应性。重要的是， GSH 水平在血液中通常为微摩尔级，但在细胞内达到毫摩尔级 ；这种显著的梯度，加上癌细胞中常见的氧化应激，有利于在肿瘤细胞内优先释放有效载荷。

二硫键连接子最常与 美登素类有效载荷 配对使用，其反应性可通过 位阻屏蔽 来调节。例如， α - 甲基取代可以显著改变还原速率并增加对硫醇 - 二硫键交换的抵抗力。一个代表性案例是 SAR3419 ，其中包含 偕二甲基取代 的空间位阻二硫键连接子被优化以生成 SPDB-DM4 构建体，最终实现了改善的抗肿瘤活性 ( 图 3 ) 。在图 3 中，连接子的抗体反应性末端和含 DM4 的末端被分别标示，以阐明 SPDB-DM4 模块是如何组装到抗体支架上的。

腙连接子

腙连接子表现出 pH 依赖性稳定性 ：它们在中性条件下相对稳定，但在酸性区室中发生酸催化水解，如内体 ( pH<6 ) 和溶酶体 ( pH<5 ) ，生成相应的酮和酰肼产物 ( 方案 1 ) 。

[图片]

腙连接子也已广泛用于 卡奇霉素家族有效载荷 ，其中有效载荷的释放通过两步激活过程进行。首先，酸不稳定的腙在酸性细胞内环境中被水解。随后，相邻的二硫键被谷胱甘肽 ( GSH ) 还原，使硫醇中间体能够形成，该中间体经历分子内环化，最终释放活性细胞毒性物种。 Mylotarg 和 Besponsa 都采用了这种通用的连接子策略；然而，它们在实践中的血浆稳定性低于预期，且基于腙的设计相对于其他可裂解连接子的优势尚未得到一致证实。

5.2.2. 酶依赖性连接子

肽连接子

蛋白酶可裂解的肽连接子 是现代 ADC 中使用最广泛的可裂解连接子类别之一。这些连接子依赖于 溶酶体蛋白酶 ，最显著的是 组织蛋白酶 B ( 以及相关的酶如组织蛋白酶 L ) ，来水解特定的肽键并触发有效载荷释放。组织蛋白酶 B 是半胱氨酸蛋白酶家族的一员；它在哺乳动物细胞的 晚期内体和溶酶体 中富集，并在多种癌症类型中经常过表达。因此，包含特定氨基酸基序 ( 例如， Val-Cit 或 Phe-Lys ) 的肽连接子被设计为在体循环中保持稳定，但在内化和运输到溶酶体后被高效裂解，从而释放游离的、具生物活性的有效载荷。

早期使用组织蛋白酶 B 底物二肽设计多柔比星前药的工作建立了这些肽触发器的关键 构效关系 ( SAR ) ： P1 位置需要亲水性残基 ( 例如，瓜氨酸或精氨酸 ) 以实现有效的酶识别，而在 P2 位置引入疏水性残基 ( 例如，苯丙氨酸、缬氨酸或丙氨酸 ) 可以显著提高血浆稳定性 ( 图 4 ) 。在后来的设计中，这种蛋白酶可裂解的二肽基序常与 自牺牲间隔子 结合使用，最常见的是 对氨基苄基氨基甲酸酯 ( PABC/PABA ) ，以促进酶 - 底物结合并减少有效载荷周围的空间位阻。在蛋白水解裂解后，该间隔子在细胞内条件下经历自发的 1,6- 消除反应 ，导致有效载荷释放以及副产物如 CO2 和反应性醌甲基化物中间体的生成。临床上， Adcetris ( 维布妥昔单抗 ) 通过采用 Val-Cit-PABC 肽连接子举例说明了这种设计 ，这提供了强大的血浆稳定性并减少了脱靶毒性 ( 图 5 ) 。此类蛋白酶可裂解连接子与多种有效载荷类别兼容，包括 微管抑制剂 ( MMAE/MMAF ) 和 DNA 损伤剂 ，其裂解动力学可通过优化肽序列以匹配不同的肿瘤和溶酶体蛋白酶环境来调整。

磷酸酶和焦磷酸酶响应性连接子

与组织蛋白酶类似， 焦磷酸酶和磷酸酶 属于一类在溶酶体区室中选择性富集的水解酶。默克公司的研究人员报道了包含 磷酸盐或焦磷酸盐基序 的连接子设计，并将其与组织蛋白酶 B 敏感的 Val-Cit-PABA 平台配对。该策略的核心目标是实现 糖皮质激素的靶向递送 ，其中磷酸盐 / 焦磷酸盐基团位于自切割间隔子 ( PABA/PABC ) 和有效载荷之间；也就是说， 磷酸盐或焦磷酸盐部分直接连接在 PABA 和效应分子之间的连接处 ，从而引入了额外的溶酶体偏向激活步骤以控制有效载荷释放 ( 方案 2 ) 。

在肿瘤细胞内化后，这些构建体的有效载荷释放被提议以逐步级联方式进行。具体来说，该序列可能涉及 组织蛋白酶 B 介导的 Val-Cit 触发器裂解 ，随后是 自牺牲间隔子 ( PABA/PABC ) 的断裂 ，然后当存在磷酸盐基序时 ( n=1 ) ，进行 磷酸酶催化的去磷酸化 。对于焦磷酸盐架构 ( n=2 ) ，可能需要一个额外的 焦磷酸酶依赖性步骤 来完成激活和有效载荷释放。该类连接子的一个关键优势在于其 增溶特性 ：亲水的、带永久电荷的磷酸盐 / 焦磷酸盐基团不仅使得高效偶联原本高度亲脂性的糖皮质激素衍生物成为可能，而且显著促进了下游纯化。这反过来可以将最终 ADC 产品中残留的游离连接子相关杂质减少到 0.10% 以下。在体外，带有磷酸盐或焦磷酸盐基序的 ADC 均显示出明确的生物活性。

葡糖苷酸连接子

在酶反应的可切割连接体中，β - 葡萄糖醛酸酶触发的设计提供了特别高的选择性。β - 葡萄糖醛酸酶是糖苷酶家族的一员，可催化β -D - 葡萄糖醛酸残基的水解。重要的是，这种酶不仅在溶酶体中富集，而且在肿瘤基质 / 微环境中也富集。因此，携带葡萄糖醛酸基序的连接子在正常组织中基本上保持惰性，在正常组织中β - 葡萄糖醛酸酶的表达通常较低，而在肿瘤中，尤其是实体肿瘤中，它们优先被激活，在实体肿瘤中，细胞外基质重塑和细胞更新可以将大量β - 葡萄糖醛酸酶释放到局部环境中 ( 图 6) 。葡萄糖醛酸键的酶切随后使有效载荷释放。该连接策略已被纳入临床研究中的多种 ADC( 例如，靶向 Trop2 的 SGN-TROP2X) ，并已证明血浆稳定性明显优于腙连接物，同时具有很强的肿瘤选择性激活。因此，β - 葡萄糖醛酸酶可切割连接物可以减少正常组织损伤，被认为非常适合实体肿瘤的应用。

有效载荷

有效载荷是抗体药物偶联物 ( ADC ) 细胞内药理活性的主要决定因素 。作为通过连接子共价连接到抗体的细胞毒性药物，有效载荷特性至关重要，因为其作用机制决定抗肿瘤效力，并因此影响 ADCs 的治疗指数和临床适用性。迄今为止，已获批 ADC 中使用的有效载荷均为 高效价药物 ，主要类别包括 奥瑞他汀 ( MMAE/MMAF ) 、卡奇霉素、美登素类 ( DM1/DM4 ) 以及 拓扑异构酶 I 抑制剂如 SN-38 和德鲁替康 ( DXd ) 。这些有效载荷通常比传统化疗药物强效得多，在某些情况下表现出 皮摩尔级 的活性。值得注意的是，已获批 ADCs 中使用的有效载荷主要靶向 微管或 DNA/DNA 相关过程 。下文总结了已上市 ADCs 中使用的有效载荷。

6.1. 微管破坏剂

微管蛋白 是微管的基本构建块。 微管靶向药物 与微管蛋白结合并破坏微管的动态聚合 - 解聚行为，导致细胞在 G2/M 期发生有丝分裂停滞 ，最终触发凋亡。在 ADC 开发中，微管导向的有效载荷主要来源于四大类： 奥瑞他汀衍生物 ( 例如， MMAE 和 MMAF ) 、美登素类 ( 例如， DM1 和 DM4 ) 、微管溶素 和 软海绵素衍生药物 ( 例如，艾立布林 ) 。

6.1.1. 奥瑞他汀

多拉司他丁样生物活性肽 ，最初从印度洋软体动物 “ Dolabella auricularia ” 中分离，具有强效的抗有丝分裂活性和对多种癌细胞类型的显著生长抑制作用。基于此结构骨架，已开发出一系列具有改善药学性质的合成衍生物，统称为 奥瑞他汀 。奥瑞他汀通过与微管蛋白结合并 扰乱微管蛋白异二聚体的构象 ，从而破坏微管动力学，并通过干扰微管蛋白依赖性 GTP 水解来抑制微管组装 / 去组装。 奥瑞他汀是 ADC 开发中使用最广泛的有效载荷类别之一 ；值得注意的是， 单甲基奥瑞他汀 E ( MMAE ) 已成功应用于已上市的 ADC Adcetris 和 Polivy ( 图 8 ) 。此外，许多临床阶段的 ADC 候选药物也采用基于奥瑞他汀的有效载荷，如 MMAE 或单甲基奥瑞他汀 F ( MMAF ) 。

[图片]

图 8. 单甲基奥瑞他汀 E(MMAE) 的结构。

该类有效载荷的 构效关系 ( SAR ) 已被深入研究，工作主要集中在 末端亚基 ( 即 N- 末端和 C- 末端 ) 的修饰 上。在这些方法中，在 N- 末端安装氨基甲酸酯官能团 已成为最常用的结构优化策略之一。

2015 年，西雅图遗传学公司的一个研究团队扩展了 ADC 有效载荷的化学空间，纳入了含 叔胺 的化合物，特别强调了 N,N- 二甲基奥瑞他汀衍生物 ( 图 9 ) 。值得注意的是，该团队报道了首批通过 季铵键 实现抗体偶联的例子之一，使得有效载荷能够共价连接到单克隆抗体上。由此产生的 ADC 在生理条件下表现出良好的稳定性，并在体外和体内显示出高效力，以及强烈的 靶点依赖性特异性 。这项工作进一步拓宽了可用于通过 ADC 进行靶向药物递送的有效载荷化学型和偶联策略库。

[图片]

图 9. 西雅图遗传学公司的连接子 - 有效载荷设计，包含 N,N- 二甲基奥瑞他汀衍生物和季铵键。

最近， Agensys 报道了另一种优化策略，即在骨架的中央亚基中引入 叠氮 ( -N 3 ) 官能团。将该修饰的化学型偶联到蛋白酶可裂解连接子后，所得构建体产生了 更亲水的衍生物 ( 图 10 ) ，并在体外和体内观察到效力的提高。该方法为连接子 - 有效载荷偶联提供了额外的技术途径，并扩展了在 ADC 设计中调节理化性质的工具箱。

[图片]

图 10. 叠氮 (-N 3 ) 奥瑞他汀衍生物的结构：新型亲水性衍生物。

在同时含有 胺 和 醇羟基 作为潜在偶联手柄的奥瑞他汀衍生物中，连接子连接通常优先通过 在胺处形成氨基甲酸酯键 来实现。西雅图遗传学随后引入了一种替代偶联策略，使用 亚甲基烷氧基氨基甲酸酯 ( MAC ) 基序实现含羟基有效载荷的抗体连接。通过在氨基甲酸酯氮附近同时引入 碱性取代基 和 吸电子基团 ，所得偶联物在保持生理稳定性的同时，在体外和体内均表现出高效力和显著的靶点依赖性特异性。

此外，乌普萨拉大学的研究人员开发了一类新的高效奥瑞他汀衍生物 ( 图 11 ) 。这些分子在 中央胺侧链 上具有抗体连接手柄，在骨架内提供了确定的偶联位点。现有研究表明，这类新型高效奥瑞他汀衍生物代表了适用于 ADC 开发的有前景的下一代细胞毒性有效载荷。

6.1.2. 美登素类衍生物 (DM1 ， DM4)

美登素类 主要通过 破坏微管组装 来发挥其抗有丝分裂作用，从而阻止微管蛋白二聚体的聚合并抑制成熟微管的形成。它们表现出 极强的抗增殖活性 ，反映了强大的细胞毒性潜力。然而，母体天然产物缺乏合适的反应性官能团，使得直接抗体偶联具有挑战性。为了克服这一限制，研究人员开发了一系列高效的 含硫代甲基 ( SMe ) 衍生物 ，其中 DM1 和 DM4 是典型例子 ( 图 12 ) 。

[图片]

图 12. 美登素、 DM1 和 DM4 的结构。

DM1 和 DM4 通常通过 二硫键 偶联到连接子上，这种基于二硫键的连接可以在体循环中提供足够的稳定性，同时在细胞内环境中保持可还原性，从而实现高效的裂解并在靶细胞内释放活性有效载荷 ( 图 13 ) 。

[图片]

图 13. DM1 和 DM4 的代表性连接子连接模式，说明二硫键型和硫化物 / 硫醚型偶联模式。

此外，一些基于美登素类的 ADCs 利用 仲羟基 作为偶联手柄，且许多此类构建体采用 转谷氨酰胺酶介导的生物偶联连接子 。例如，源自 达雷妥尤单抗 的 ADC 已被证明可以选择性地将 DM4 递送至 CD38 高表达的癌细胞。最近， ImmunoGen 报道了一种下一代 ADC ，其特点是包含 含硫美登素类似物 有效载荷，通过 高度稳定的三肽连接子 偶联到抗体上，同样使用了相同的仲羟基连接位点 ( 图 14 ) 。与早期的美登素类 ADC 设计相比，在该连接子架构中 增加亚甲基单元的数量 增强了旁观者杀伤效应，并在小鼠模型中改善了治疗效果。为清晰起见，图 14 明确标示了用于连接子安装的 仲羟基 ，从而显示了有效载荷转化为连接子兼容前体的位点。

6.1.3. 微管溶素

微管溶素 是 微管聚合的强效抑制剂 ，可诱导分裂细胞中细胞骨架的快速崩溃，从而触发凋亡。它们是天然存在的 四肽 ，由 Mep 、 Ile 、 Tuv 和 Tut ( R3=OH ) 或 Tup ( R3=H ) 单元组成 ( 图 16 ) 。

[图片]

图 16. 代表性的微管溶素骨架，显示 Tut/Tup 模块及其连接子兼容的偶联手柄。

在 ADC 开发中，微管溶素骨架上多个潜在的偶联手柄已被广泛探索。一个明确的连接位点是 Tut 或 Tup 模块中的羧酸官能团 。例如， Endocyte 的 EC1428 就是通过 酰肼部分 将该羧基偶联到连接子上构建的 ( 图 17 ) 。使用类似的衍生化策略， Oncomatryx 在相同位置引入了包含 PABA-Val-Cit 基序的可裂解马来酰亚胺连接子，以实现受控的细胞内有效载荷释放。

[图片]

图 17. 代表性的基于微管溶素的偶联策略，聚焦于 Tut/Tup 羧酸部分，显示酰肼偶联和 EC1428 样构建体中可裂解连接子片段的位置。

阿斯利康、百时美施贵宝 和 辉瑞 采用了另一种修饰途径，即通过 Tup/Tut 基序中苯环的衍生化 来实现连接子连接，从而在不破坏药效团的情况下创建合适的偶联手柄 ( 图 18 ) 。与此同时，大量工作也验证了涉及 Mep 取代基 的连接子偶联策略。值得注意的是， Ingenica 的研究人员报道， 去甲基 -Mep 类似物 可以保留强效的细胞毒性，因此代表了极具吸引力的 ADC 有效载荷候选物；重要的是，该骨架上的 仲胺 可以用 不可裂解的马来酰亚胺 - 己基连接子 进行官能化，从而实现稳健的抗体偶联。

[图片]

图 18. 通过修饰的苯基连接的微管溶素衍生有效载荷示例。

Oncomatryx 进一步证明，当 Mep 部分被带有 仲胺 的替代基序替换时，通过 氨基甲酸酯键 安装可裂解连接子为 ADC 构建提供了一条有效途径。值得注意的是， Genentech 报道了一种独特的策略，即使用 季铵手柄 将连接子偶联到含 叔胺 的有效载荷上。在此类有效载荷中引入 Mc-val-cit-PABA 连接子可显著增加偶联物的亲水性，并可提高其在体循环中的稳定性。 西雅图遗传学 采用了一种概念上相关的方法，即使用 葡萄糖醛酸苷基连接子 来增强亲水性，并利用癌细胞中升高的 β- 葡萄糖醛酸酶 活性，从而实现有效载荷的选择性细胞内裂解。

此外， 阿斯利康 /MedImmune 开发了 双特异性 ADC MEDI4276 ，它靶向 HER2 上的两个不同表位。双特异性结合可能增强受体簇集并增加内化，可能增强细胞内有效载荷释放和肿瘤细胞杀伤。 MEDI4276 由一个 双特异性抗 HER2 抗体 通过 不可裂解连接子 偶联到微管溶素衍生有效载荷 AZ13599185 上组成， DAR 为 4 ( 图 19 ) 。在临床前研究中， MEDI4276 显示出强大的抗肿瘤活性，而 肝毒性 在临床评估中成为主要的剂量限制性毒性。在图 16 中，携带连接子的有效载荷相对于示意性抗体显示，以便更容易理解 MEDI4276 的连接位点和整体架构。

6.1.4. 艾立布林

艾立布林 是源自 软海绵素 B ( 一种最初从海洋海绵中分离的大环天然产物 ) 的全合成类似物 ( 图 20 ) 。它选择性地靶向 微管正端的 β- 微管蛋白 ( + ) 端 ，主要通过 抑制微管聚合 / 延伸 ，同时对微管解聚影响极小。这种独特的作用机制支撑了其在某些紫杉醇耐药情况下的临床活性，允许对紫杉醇难治的患者保留治疗效果。 2010 年 11 月，美国食品药品监督管理局 ( FDA ) 批准艾立布林用于治疗 转移性乳腺癌 。 将艾立布林作为细胞毒性有效载荷的 ADCs 引起了关注，因为它们可能赋予 显著的旁观者效应 ，支持在异质性肿瘤中的潜在临床应用。此外， 艾立布林对 P- 糖蛋白 ( P-gp ) 介导的外排相对不敏感 ，这可能进一步拓宽其在耐药性疾病中的应用范围。

[图片]

图 20. 软海绵素 B 和艾立布林的结构。

Earl F. Albone 及其同事设计了一种基于艾立布林的 ADC ，通过在有效载荷的 C-35 伯胺 处安装连接子。所得偶联物对卵巢癌细胞系 IGROV1 显示出显著的抗增殖活性 ( IC50≈20pmol/L ) 。在非小细胞肺癌 ( NSCLC ) NCI-H2110 异种移植模型中，以 5mg/kg 剂量给药该 ADC 产生了 完全的肿瘤根除 ，支持了艾立布林作为微管靶向有效载荷用于 ADC 开发的可行性。基于这一概念，通过 C32 侧链的药物化学优化 ，要么 减弱含胺片段的碱性 ，要么 增加整体亲脂性 ，产生了艾立布林衍生物，这些衍生物在多个异种移植模型中显示出广泛的体外和体内抗肿瘤活性 ( 图 21 ) 。重要的是，这些修饰旨在 改善口服生物利用度、增强脑渗透 ( 包括增加脑脊液暴露 ) ，并 降低对 P- 糖蛋白 ( P-gp ) 介导外排的敏感性 ，提示其不仅在系统性恶性肿瘤中，而且在 脑肿瘤 等适应症中具有潜在用途。

6.1.6. 抗有丝分裂 Eg5 抑制剂

驱动蛋白纺锤体蛋白 ( KSP ) ，也称为 Eg5 或 KIF11 ，是一种 ATP 依赖性运动蛋白 ，在有丝分裂期间需要用于 中心体分离 。抑制 Eg5 会破坏纺锤体组装并使细胞停滞在有丝分裂期，使 KSP 抑制剂成为抗癌治疗的有吸引力的策略 。驱动蛋白纺锤体蛋白 ( KSP ，也称为 Eg5 或 KIF11 ) 是一种 ATP 依赖性运动蛋白，参与细胞周期进程中的中心体分离。 Eg5 在 血液系统恶性肿瘤 ( 如急性髓系白血病 ( AML ) 细胞和弥漫性大 B 细胞淋巴瘤 ( DLBCL )) 和 实体瘤 ( 包括 乳腺癌、膀胱癌和胰腺癌 ) 中均高表达。这种表达模式与 不良临床结局 密切相关，使 Eg5 成为癌症治疗的一个极具吸引力的靶点 。 诺华 开发的 Eg5 抑制剂 已被用作 ADC 有效载荷，并通过 不可裂解连接子 偶联到抗体上，用于靶向 HER2 表达细胞 ( 图 26 ) 。

6.2. DNA 损伤剂

与微管抑制剂相比， DNA 导向的细胞毒性药物 可通过 双链断裂、烷基化、嵌入和交联 等机制损伤基因组 DNA ，从而在 整个细胞周期 中发挥细胞毒性效应，并常在实体瘤中表现出强效活性。由于每个细胞的 功能性 DNA 靶点数量 相对于丰富且动态的微管网络是有限的，等量的细胞内有效载荷载量对于 DNA 靶向弹头可转化为更有效的肿瘤细胞杀伤。此外，携带 DNA 活性有效载荷的 ADC 可能在 抗原密度较低 的肿瘤中保留疗效，这是许多下一代 ADC 项目越来越多地采用 DNA 靶向有效载荷类别的部分原因。

DNA 靶向有效载荷可大致分为 DNA 损伤剂 和 拓扑异构酶抑制剂 。 DNA 损伤剂类别包括关键类型如 卡奇霉素、吡咯并苯二氮卓 ( PBDs ) 和倍癌霉素 。相比之下， 拓扑异构酶 I 抑制剂 主要由 喜树碱衍生化合物 代表，包括 依喜替康、 SN-38 和德鲁替康 ( DXd ) 。

6.2.2. DNA 双链断裂诱导剂：卡奇霉素

卡奇霉素 是研究最广泛的 烯二炔抗生素 之一，其独特的结构特征和机制复杂的 DNA 损伤活性已使其成为 ADC 研究中的主要有效载荷类别 ( 图 31 ) 。基于 卡奇霉素的偶联策略 已通过其在已上市 ADCs Mylotarg 和 Besponsa 中的应用得到临床验证。

6.2.4. 拓扑异构酶 I 抑制剂：喜树碱

喜树碱 ( CPT ) 及其衍生物是典型的 拓扑异构酶 I ( TOP1 ) 抑制剂 。它们通过 稳定 TOP1 介导的 DNA 单链断裂中间体 来发挥作用，从而形成 DNA-TOP1- 抑制剂三元复合物 。当该稳定复合物遇到 复制叉 时，可转化为 DNA 双链断裂 ，导致细胞毒性。天然 CPT 是一种 五环天然产物 ，其极差的 水溶性 限制了其更广泛的临床应用。相比之下，水溶性前药 伊立替康 已被批准用于治疗 转移性结直肠癌 。 SN-38 是由伊立替康通过 肝脏羧酸酯酶介导的代谢 生成的，是主要的活性代谢物；然而， SN-38 可以发生 内酯环开环 ，导致无活性的 羧酸盐形式 ( 图 37 ) 。

[图片]

图 37. 喜树碱 ( CPT ) 和 SN-38 的结构。

Immunomedics 建立了两种主要的偶联策略，用于将 SN-38 偶联到抗体上。在一种方法中，连接子通过更具反应性的 C-10 酚羟基 连接，形成化学稳定的 氨基甲酸酯键 。在第二种策略中，偶联在 C-20 羟基 上进行，该位置被认为对体内活性至关重要，同时有助于 稳定内酯环 ，从而保留活性喜树碱药效团。

依喜替康 ( DX-8951f ) 代表了另一种适用于 ADC 有效载荷开发的高效 TOP1 抑制化学型 ( 图 38 ) 。作为喜树碱类似物，依喜替康在 环己基环的 7- 和 9- 位 之间有一个 胺取代基 。该 氨基 提高了水溶性，而环己基环赋予的 构象刚性 有助于在活性内酯和非活性水解羧酸盐形式之间维持有利的平衡。氨基 / 羟基官能团的进一步衍生化产生了 德鲁替康 ( DXd ) 类似物。两种衍生物均保留了依喜替康骨架特征性的生物活性。

[图片]

图 38. 依喜替康衍生物 DX-8951f 的结构。

依喜替康骨架上的 游离羟基和氨基 提供了明确的偶联手柄，可以通过 酶可裂解的四肽连接子 ( 如 Gly-Gly-Phe-Gly ) 偶联到有效载荷上。在与抗 HER2 抗体偶联后，所得 ADC 在临床评估中对 HER2 阳性恶性肿瘤显示出显著的治疗前景。

虽然 DXd 中的 环己胺环 有助于稳定生物活性内酯形式，但相关的 立体中心 增加了合成复杂性并使构效关系 ( SAR ) 研究复杂化。为了解决这一限制， ImmunoGen 的研究人员开发了一系列下一代 CPT 类似物，其中 环己胺环被打开 以消除额外的手性中心，从而提高了与单克隆抗体偶联的适用性。当偶联到抗人表皮生长因子受体 ( HuEGFR ) 抗体时，所得 ADCs 在 EGFR 阳性的 HSC-2 异种移植模型中显示出显著疗效。

6.2.5. 拓扑异构酶 II 抑制剂：多柔比星和 PNU-159682

骨肉瘤 是儿童和青少年中最常见的恶性骨肿瘤， 40−50% 的患者在手术后出现复发或远处转移，导致 5 年生存率低于 30% 30% 。 多柔比星 ，一种 蒽环类抗生素 ，仍然是骨肉瘤的一线化疗药物之一。它 嵌入 DNA 双螺旋 ，阻止链分离，从而干扰 DNA 复制和 RNA 合成 。然而，当用作 ADC 有效载荷时，多柔比星的固有效力通常不足，促使开发更有效的蒽环类衍生物。

PNU-159682 ，是 奈莫柔比星 的肝脏代谢物，是一种 Topo II 抑制剂 ，其细胞毒性约为多柔比星的 100 倍 。其生物效力约比奈莫柔比星高 三个数量级 ， IC50 IC50 值在 20–100pM 范围内，并且它不是常见外排转运蛋白的底物。从奈莫柔比星到 PNU-159682 的生物转化已被确定为肝脏中的关键 代谢激活途径 ( 方案 4 ) 。

然而，由于其非常高的固有效力，卡马霉素类化合物通常 选择性有限 ，因此可能与 显著毒性 相关。因此，高细胞毒性的卡马霉素衍生物非常适合作为 ADC 弹头 ，其中所需的效力得以保留，而靶向递送通过限制正常组织中的暴露来改善耐受性。在基于卡马霉素的有效载荷类似物的设计中，一种常见策略是在 P2 位置引入甲硫氨酸砜衍生物 ( 如卡马霉素 B 中 ) ，而非卡马霉素 A 中存在的甲硫氨酸亚砜。这种修饰避免了由亚砜立体异构体混合物引起的额外结构复杂性。

第一代卡马霉素类似物 在 P4 末端 引入了一个 胺手柄 ，但该连接位点被证明是次优的，并与有效载荷细胞毒性的显著降低相关。在 第二代类似物 中，胺被安装在 P2 侧链 上，通过 磺酰基连接的短乙胺取代基 延伸获得了最有利的结果。 第三代设计 进一步通过 芳基连接子 连接砜和胺，从而降低了分子的整体碱性。 第二代和第三代有效载荷 均保留了强效的体外活性，并成功偶联到可裂解或不可裂解连接子上。然而，在所评估的癌细胞系中，所得 ADC 在肿瘤细胞杀伤活性方面并未超越曲妥珠单抗。

6.3.5. RNA 聚合酶 II 抑制剂：鹅膏蕈碱

在 ADC 技术的背景下，使用 鹅膏蕈碱 ( 强效 转录抑制剂 ) 作为有效载荷是一个相对较新的方向。九种天然存在的鹅膏蕈碱具有一个共同的核心结构：一个由八个 L- 氨基酸 形成大环的 双环八肽 ，在 色氨酸 和 半胱氨酸 残基之间有一个 亚砜桥 。三个含 羟基 的侧链赋予良好的水溶性，并在与 RNA 聚合酶 II 的结合中起关键作用。其中， α- 鹅膏蕈碱 和 β- 鹅膏蕈碱 约占天然鹅膏蕈碱的 90% 。

迄今为止，已有三种主要的鹅膏蕈碱偶联策略被开发用于 ADC 构建。第一种涉及将 β- 鹅膏蕈碱的羧基 偶联到 IgG 的赖氨酸残基 上。尽管这种方法产生的 ADC 具有良好的血浆稳定性和高细胞毒性，但整体生物偶联效率较低。第二种策略利用 二氢异亮氨酸的羟基 作为连接位点；在此位置引入了一个 基于谷胱甘肽的连接子 ，然后偶联到赖氨酸残基上，产生了具有优异体外细胞毒性和体内抗肿瘤活性的 ADC 。然而， 血清羧酸酯酶 可以裂解连接子，损害了循环稳定性。 第三种也是现在的标准方法 使用 色氨酸的 6'- 羟基 作为偶联位点。通过该酚羟基与各种连接子基序的 醚化 ，产生具有高稳定性和效力的 ADCs 。鹅膏蕈碱骨架中的其他氨基酸，如 羟脯氨酸、甘氨酸、异亮氨酸和半胱氨酸 ，要么是化学惰性的，要么是与 RNA 聚合酶 II 结合所必需的，因此不适合进行修饰 ( 图 45 ) 。

一种代表性的基于鹅膏蕈碱的 ADC 是 HDP-101 ，它使用一种为增强稳定性而优化的 合成鹅膏蕈碱类似物 ( 图 46 ) 。与天然鹅膏蕈碱相比，该类似物 缺少色氨酸上的 6′ - 羟基 ，并将 亚砜桥 替换为 硫醚 。一个 组织蛋白酶 B 可裂解的连接子 通过 酰胺键 连接到 天冬氨酸残基 的侧链上。

最近， Park 及其同事开发了 OHPAS ，一种用于含酚有效载荷的新型 二芳基硫酸酯连接子基序 。在此设计中，一个芳基来自酚类有效载荷，另一个来自酚类连接单元。将 OHPAS 化学应用于 曲妥珠单抗 - 鹅膏蕈碱 ADCs 产生了在体外和体内均具有强效细胞毒性的构建体，进一步扩展了鹅膏蕈碱类 ADCs 的连接子库。

6.4. 创新有效载荷模式

除了传统的细胞毒性小分子外，多种新兴有效载荷模式正在被探索以进一步拓宽作用机制并改善治疗指数，包括 靶向蛋白降解 ( PROTAC ) 、 肽 - 药物偶联物 ( PDCs ) 、 近红外光免疫治疗 ( NIR-PIT ) 、 放射性核素药物偶联物 ( RDCs ) 和 免疫激动剂有效载荷 。

6.4.1. 基于 PROTAC 的有效载荷

抗体 -PROTAC 偶联物 代表了一种新兴的治疗模式，它将抗体药物偶联物 ( ADC ) 范式与 蛋白水解靶向嵌合体 ( PROTAC ) 技术相结合。在这种设计中，抗体的高靶点特异性被用来选择性地将 具有催化性蛋白降解能力的 PROTAC 有效载荷 递送至特定的细胞群体中。与通常采用细胞毒性小分子有效载荷的传统 ADCs 不同，这些偶联物使用 PROTACs 作为效应部分，通过 泛素 - 蛋白酶体系统 消除疾病相关蛋白。在机制上，偶联物首先识别并结合靶细胞表面的特异性抗原；随后形成的复合物通过 内吞作用 内化，接着进行 溶酶体加工 ，该加工切割连接子并在细胞内释放 PROTAC 。释放的 PROTAC 随后 催化性地 发挥作用， 招募 E3 泛素连接酶 与靶蛋白形成三元复合物，促进靶蛋白泛素化并将其引导至 蛋白酶体降解 。由于 PROTACs 的 催化性、事件驱动 性质， 亚化学计量 的量可以通过多个降解周期诱导持续的靶点耗竭。

这种策略有可能解决当前治疗方法的若干局限性。首先， 抗体介导的靶向递送 可以增加 PROTAC 在病变组织中的积累，同时减少在正常器官中的暴露，从而改善预期的安全性。其次，由于其药理学是 事件驱动 的，旨在消除蛋白质而非持续抑制其活性，这种方法可能扩展可靶向的范围，包括传统上被认为是 “ 不可成药 ” 的靶点。例如，将 BRD4 导向的 PROTAC 偶联到 抗 HER2 抗体 上，可以产生一个大约 150kDa 的大分子构建体，每个抗体的平均药物抗体比 ( DAR ) 为 4 个 PROTAC 单元 ( 图 47 ) 。该设计旨在实现对 HER2 阳性肿瘤细胞中 BRD4 的选择性细胞内降解 ，结合了肿瘤靶向特异性和催化性靶点耗竭，从而显示出良好的 转化潜力 。图 47 显示了代表性的 PROTAC 有效载荷结构，而非抗体 -PROTAC 偶联物的完整化学结构。

6.4.2. 肽 - 药物偶联物 (PDCs)

肽 - 药物偶联物 ( PDCs ) 是一类新兴的靶向治疗药物，通常包含三个关键要素： 归巢肽 、 细胞毒性有效载荷 以及共价偶联两者的 连接子 。相对于抗体药物偶联物， PDCs 具有几个潜在优势，包括 分子尺寸更小 、 增强的肿瘤组织渗透性 、 降低的免疫原性 ，以及通过 固相肽合成 实现的经济高效的大规模生产。此外， PDCs 可能表现出 有利的药代动力学可调性 和 改善的批间均一性 ，共同将它们定位为有前景的下一代靶向抗癌药物。根据特定的归巢肽和连接子设计， PDCs 通常通过两种主要机制运作。在一种模式中，完整的偶联物通过 受体介导的内吞作用 被内化，随后细胞内释放有效载荷以引发细胞毒性。在另一种模式中，偶联物在 肿瘤微环境 中选择性裂解，例如，通过 肿瘤相关酶 或微环境条件，从而在 细胞外 释放有效载荷，其随后被肿瘤细胞摄取以发挥治疗效果。

迄今为止，全球仅有 两款 PDC 产品 获得监管批准。其中， Lutathera ( 177 Lu-DOTATATE ) ，一种放射性标记的 生长抑素类似物肽 ，已获批通过靶向 生长抑素受体 治疗 胃肠胰腺神经内分泌肿瘤 ( GEP-NETs ) 。据报道，该产品在 2023 年的收入约为 6.05 亿美元 。相比之下， Pepaxto ( 美法仑氟芬酰胺 ) 已从市场撤回，主要归因于 靶向选择性不足 和相对于现有替代方案 不利的获益 - 风险 状况。

6.4.3. 近红外光免疫治疗 (NIR-PIT) 有效载荷

近红外光免疫治疗 ( NIR-PIT ) 是一个新兴的靶向抗癌平台，其核心组件包括 肿瘤特异性单克隆抗体 、 光活化剂 以及共价偶联两者的 连接子 ，从而在概念上将 NIR-PIT 定位于抗体药物偶联物 ( ADC ) 框架内。该模式与 近红外光照射设备 结合实施：抗体能够选择性地递送并积聚在肿瘤部位，随后局部 近红外光照射 激活偶联的 光敏剂 以引发高度特异性的 生物物理效应 。通过这样做， NIR-PIT 可以实现强效的肿瘤细胞根除，同时最大限度地保护周围的正常组织。

NIR-PIT 的机制以 双重作用模式 为特征。首先，在近红外光激活后，偶联物诱导 抗体结合的肿瘤细胞 发生快速的、局部的破坏，导致有效的靶细胞杀伤。其次，由此产生的细胞死亡可伴随 免疫原性细胞死亡 ( ICD ) ，促进 肿瘤抗原 和 危险相关信号 的释放，从而引发 多克隆抗肿瘤免疫反应 。这种免疫放大可能有助于清除由于 抗原表达异质性 、 非均匀药物分布 或 次优光剂量 而逃脱直接光毒性的残留恶性细胞，最终提高整体治疗效果。此外， NIR-PIT 易于与已确立的 免疫检查点抑制剂 ( 例如，抗 PD-1 、抗 PD-L1 或抗 CTLA-4 抗体 ) 联合使用，这可以进一步 增强抗肿瘤免疫 并改善治疗结果。

与传统 ADCs 相比， NIR-PIT 中使用的 “ 有效载荷 ” 不是经典的细胞毒性小分子，而是一种 光敏剂 ，以水溶性 酞菁衍生物 IRDye700DX ( IR700 ) 为例 ( 图 48 ) 。在抗体与肿瘤相关抗原结合后，近红外光照射触发 IR700 的 光化学转化 ，伴随其 亲水侧链的裂解 / 释放 并导致 疏水性急剧增加 。这种物理化学变化 扰乱膜完整性 ，最终导致快速、高度选择性的 免疫原性细胞死亡 ( ICD ) 和 肿瘤限制性细胞毒性 。尽管光免疫治疗 ADC 类构建体的临床和商业前景仍有待完全确立，但基于此原理开发 新靶点 和 下一代光活化效应器 可能为 ADC 领域内的创新开辟一条有前景的途径。

6.4.4. 放射性核素药物偶联物 (RDCs)

放射性药物偶联物 ( RDCs ) 可以在 不需要细胞内化 的情况下发挥治疗活性，并且它们通常被设计为具有 不可裂解 的结构以增强在体循环中的稳定性。此外， RDCs 携带的 放射性核素 可能被优先保留在 肿瘤微环境 中，这可以减少对正常组织的脱靶照射，并赋予其独特的 安全性优势 。在结构上， RDCs 通常由三个核心元素组成： (i) 靶向部分 ，最常见的是 单克隆抗体 或 小分子配体 ，选择性识别肿瘤相关标志物； (ii) 连接 / 螯合模块 ，包含将靶向单元与 螯合剂 偶联的 共价连接子 ，以及通过 金属 - 配体相互作用 配位并稳定放射性核素的 螯合剂 ； (iii) 效应组件 ，即根据其 衰变特性 和 发射谱 为治疗或诊断目的选择的 放射性核素 。这种模块化设计实现了精确的肿瘤靶向和可控的放射学效应。

根据所选的效应模块， RDCs 可大致分为 诊断性 和 治疗性 构建体。诊断性 RDCs 主要开发用于 分子影像 ，最常见的是 PET 和 SPECT ，因此使用发射 正电子 ( β+ 发射体 ) 用于 PET 或 单光子 ( γ 发射体 ) 用于 SPECT 的放射性核素。代表性的诊断性放射性核素包括 68 Ga 、 18 F 、 64 Cu 、 89 Zr 、 99 mTc 和 111 In 。相比之下，治疗性 RDCs 旨在递送能够 诱导 DNA 双链断裂 、 根除缺氧肿瘤细胞群体 并提供 交叉火力效应 ( 可将辐射剂量扩展到抗原阳性细胞之外，部分解决 瘤内异质性 ) 的细胞毒性辐射。因此，治疗性放射性核素通常是 长程 β− 发射体 和 / 或 高线性能量转移 ( LET ) α 发射体 ，代表性例子包括 225 Ac 、 223 Ra 、 213 Bi 、 211 At 、 177 Lu 、 90 Y 、 131 I 和 188 Re 。

放射性药物的开发正日益从具有单一诊断或治疗功能的药物转向 整合的治疗诊断范式 。放射性核素如 64 Cu 和 177 Lu 已引起相当大的关注，因为它们可以同时支持 分子影像 和 放射性核素治疗 ，并且它们的临床探索已从传统的肿瘤学应用扩展到新兴适应症，包括 神经退行性疾病 。就中国的本土创新而言， 131 I - 美妥昔单抗 ( 利卡汀 ) 代表了 全球首个获批的用于治疗肝细胞癌的放射性标记抗体偶联物 ，是一项里程碑式的成就。此外，下一代候选药物如 177 Lu -EB-FAPI 已进入 III 期临床评估 ，突显了该领域的持续创新和转化动力。

6.4.5. 免疫激动剂 (TLR 和 STING) 作为有效载荷

免疫刺激抗体偶联物 ( ISACs ) 代表了一种新兴的免疫治疗模式，旨在通过将 免疫调节激动剂有效载荷 偶联到 肿瘤靶向抗体 上来实现精准的免疫激活。与主要依赖直接细胞毒性的传统 ADCs 不同， ISACs 被认为通过 多步骤机制 运作： (i) 抗体部分选择性地识别并结合 肿瘤相关抗原 ； (ii) 由此产生的 免疫复合物 通过 Fc 受体介导的摄取 被 抗原呈递细胞 ( APCs ) 内化； (iii) 在 APCs 内，偶联的激动剂结合并激活 Toll 样受体 ( TLR ) 信号通路 。这种设计能够将免疫激动剂 优先递送至肿瘤微环境 ，从而启动 先天免疫激活 ，并随后促进 适应性抗肿瘤免疫反应 。通过将免疫刺激活性限制在预期的作用位点， ISACs 可以减轻与 全身性给予免疫刺激剂 常相关的 系统性毒性 ，提高治疗效果并降低广泛不良事件的风险。

作为一种新兴的治疗策略， 免疫刺激抗体偶联物 ( ISACs ) 主要采用 IgG1 同型抗体作为递送支架。 IgG1 提供了有利的 可开发性属性 ，包括 高结构稳定性 和 长血清半衰期 ，有助于维持治疗相关的全身暴露。此外， IgG1 对 Fcγ 受体 ( FcγR ) 表现出 高亲和力 ， FcγR 广泛表达于多种免疫细胞亚群上； FcγR 的结合可以促进 肿瘤局部免疫细胞的招募和激活 ，从而支持 免疫介导的抗肿瘤活性 。

在有效载荷设计方面， ISACs 最常整合 小分子免疫调节剂 ，如 Toll 样受体 ( TLR ) 激动剂 ( 例如， TLR7/8/9 激动剂 ) 或 干扰素基因刺激因子 ( STING ) 激动剂 。这些 免疫激活有效载荷 旨在 重编程肿瘤免疫微环境 并 放大宿主抗肿瘤免疫 ，解决了传统 ADC 主要依赖直接细胞毒性机制而非免疫增强的关键局限性。尽管有这些机制上的优势， ISACs 整体仍处于 早期开发阶段 。与 ADC 相比， ISAC 在优化 疗效 - 安全性平衡 方面提出了更复杂的挑战，因为需要严格控制免疫激活的 强度 、 位置 和 持续时间 。

挑战与未来方向

尽管取得了显著进展，但 ADC 开发仍面临几个关键挑战。 脱靶毒性 由有效载荷过早释放或与表达低水平 TAA 的正常组织的交叉反应性引起，导致如 骨髓抑制、神经病变和心脏毒性 等毒性。 肿瘤异质性和获得性耐药 由可变的 抗原表达 、 受损的内化 或通过 P- 糖蛋白 的有效载荷外排引起，限制了疗效。 药代动力学限制 ，包括 异质性 DAR 、 快速清除 和 免疫介导的 ADC 降解 ，影响治疗一致性。 生产复杂性 ，特别是对于 位点特异性偶联 和 质量控制 ，导致高生产成本。

为应对这些挑战，正在探索若干创新策略。 双特异性 / 多特异性 ADCs 靶向两个或多个抗原以 增强肿瘤特异性 并 克服异质性 。由 肿瘤特异性信号 ( 例如， 缺氧 、 活性氧物种 、 胞外蛋白酶 ) 激活的 智能连接子 ，改善有效载荷释放的特异性。 新型有效载荷类别 ，包括 免疫调节剂 ( 例如， TLR 激动剂 、 PD-1 抑制剂 ) ，触发抗肿瘤免疫并扩大治疗范围。 联合疗法 ，将 ADCs 与 免疫检查点抑制剂 、 化疗 或 放疗 结合，增强协同抗肿瘤效应。 个体化医疗 ，通过识别 预测性生物标志物 ( 例如， 抗原表达 、 连接子裂解酶水平 ) ，选择最可能从 ADC 治疗中获益的患者。

抗体药物偶联物 是一类快速发展的 靶向抗癌药物 ，已经改变了 血液系统恶性肿瘤 和 实体瘤 的治疗格局。通过 抗体、连接子和有效载荷 的合理设计， ADCs 实现了 精确的肿瘤靶向 和 强效的细胞毒性 ，为 难治性癌症 患者带来了新的希望。从 第一代到第三代 ADC 的演进解决了关键的限制， 位点特异性偶联 、 优化的连接子 和 超强效有效载荷 推动了临床成功。然而， 脱靶毒性 、 耐药性 和 生产复杂性 等挑战依然存在。 双特异性 ADCs 、智能连接子、新型有效载荷 和 联合疗法 的未来进展预计将进一步提高疗效和安全性。随着我们对 ADC 生物学 和 肿瘤异质性 理解的加深， ADCs 将继续在 精准肿瘤学 中发挥核心作用，为更有效和 个体化的癌症治疗 铺平道路。
