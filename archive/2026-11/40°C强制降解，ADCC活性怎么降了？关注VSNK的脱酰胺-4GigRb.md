文献主要知识点 ：

1. 到底是什么影响ADCC活性？

非岩藻糖基化和V S N 325 K脱酰胺是ADCC活性影响的两大关键因素，决定性原因在于Fc上 P329周围的疏水核心 。N325紧邻P329，其脱酰胺可能改变局部三维结构，干扰Fc与FcγRIIIa的结合界面。

2. N325脱酰胺为什么在25°C较少？

在中性pH下该位点被埋藏在局部三维结构中，仅在 酸性pH 下暴露，随后在 高温 下发生脱酰胺。

3. 脱酰胺的 色谱行为

Trypsin酶切时，VSNK理论肽 2.7min ，脱酰胺后分别在 3.2 和 3.3min ；Glu-C酶切时，理论肽 23.5min ，脱酰胺肽分别在 23.2 和 24.2 min。

这说明了一个脱酰胺位点也可以产生 两个 脱酰胺肽段 ，同时脱酰胺肽段保留时间 可以 提前 也可以 推后 ，这非常典型的证明了isoD的存在。

4. 脱酰胺质谱鉴定中的同位素峰

同位素峰型变化可以很好的证明脱酰胺的真实性，即使 二级MS/MS谱不好 或 肽段共流出时 同样适用 ，需要予以关注。

摘     要

PART 01

Technology

阿斯利康 ( AstraZeneca )于2020年 【1】 发表在《Scientific Reports》的 研究，发现一种IgG1单抗在 40°C stress 4个月后，其 ADCC活性丧失超过一半 ；使用尺寸排阻色谱和离子交换色谱分离出各种大小变异体和电荷变异体，对这些组分进行表征，发现一种罕见的Fc修饰 N325脱酰胺 与 ADCC活性 丧失 呈正相关 。

进一步的SRP ( 表面等离子体共振 ) 研究表明，该修饰破坏了IgG1 Fc与FcγRIIIa之间的结合，从而导致ADCC活性下降；使用 N325/D和N325/Q突变体 ，确认了N325脱酰胺对ADCC的影响。作者推测，N325脱酰胺改变了局部三维结构，从而可能干扰与效应细胞的结合和相互作用。

由于N325脱酰胺对生物活性的影响，对于作用机制包括ADCC的产品而言，N325脱酰胺是一个 关键质量属性 ；充分理解N325脱酰胺的关键性并进行适当监测，有助于确保IgG1或Fc融合产品的安全性和有效性。

结果部分

PART 02

Technology

1. 显著增加的酸峰和显著降低的ADCC活性

为了理解降解途径并建立CQA清单，将IgG1-A暴露于高温条件： 25°C 10个月 和 40°C 4个月 。有趣的是，25°C孵育样品保留 94% 的ADCC活性，但 40°C 应激样品仅表现出 35% 的ADCC活性。

为鉴定活性丧失原因，首先使用SEC进行分析，如 图1a ，40°C应激样品比25°C孵育样品含有略多的二聚体和片段， 但两个样品仍以单体为主 。富集出SEC单体组分，来自40°C样品的单体，仍表现出低于50%的ADCC活性(如图2)，表明去除其他大小变异体(如二聚体和片段) 并不能恢复 ADCC活性。

如 图1b ，进一步使用IEC分离来自25°C和40°C样品的 SEC单体组分 中的不同电荷变异体，相对活性见图2。有趣的是：

a. 40°C样品中，所有酸性组分的ADCC活性均 低于 主峰，而25°C样品酸峰表现出与主峰 相似 的 活性；

b. 40°C样品ADCC活性从主峰(82%)到前峰5(12%) 逐渐降低 ，表明这些级分可能含有 浓度逐渐增加的某些电荷变异体 ，从而干扰ADCC活性。

[图片]

2. PTMs分析锁定N325脱酰胺

如 表1 ，总结了所有IgG1-A IEC组分中显著水平的PTM。酸性组分中存在 四种高水平PTM ：M252氧化、N325脱酰胺、N384/N389脱酰胺和HC N端焦谷氨酸环化。

[图片]

根据Fc受体结合研究，M252氧化与ADCC活性无关。HC N端pE水平也与IgG1-A中ADCC活性丧失无关。

为评估N325或N384/N389脱酰胺与ADCC活性之间的相关性，将IgG1-A在无IgG人血清中37°C孵育4周， 以产生相当水平的N384/N389脱酰胺(4.4%增至35.0%) ，而 N325脱酰胺没有增加 (从2.0%增至2.1%)。血清孵育样品的相对ADCC活性为88%，表明 N384/N389脱酰胺对ADCC活性没有影响 。

基于这些结果，我们得出结论： N325脱酰胺可能是40°C中ADCC活性丧失的主要原因 。

3. N325脱酰胺与ADCC强相关

如 图3a ，N325脱酰胺比例与ADCC活性之间存在强负相关； 图3b ，FcγRIIIa结合与N325脱酰胺比例呈强负相关；如 图3c ，FcγRIIIa结合与ADCC变化之间的相关性呈线性。

这些结果表明，ADCC效应功能的破坏 主要是N325脱酰胺 的结果。

[图片]

4. N325突变体进一步验证

为进一步确认仅N325脱酰胺即可消除IgG1的ADCC活性，使用N325位点的D或Q 定点突变体 (IgG1-B和IgG1-C)。突变通过质谱分析和HILIC糖基化分析，确保亲本和突变体具有相似的去岩藻糖基化水平。

如 图4 ， N325突变导致ADCC完全丧失和FcγRIIIa结合降低 ，表明N325对FcγRIIIa结合和效应功能必不可少，支持我们关于N325脱酰胺导致ADCC活性丧失的结论。

[图片]

5. N325位点的监测挑战

N325位点过去被忽视，部分原因是胰蛋白酶肽图的技术挑战，IgG1抗体的胰蛋白酶消化产生四肽323VSNK326，这是一种亲水肽，通常洗脱在反相高效液相色谱的死体积附近。当该肽与其脱酰胺产物共洗脱，导致其 同位素分布 中第二个同位素峰增加 。 (注：同位素分布是脱酰胺鉴定的非常重要的依据)

如 图5 ，可见一个奇怪的双峰现象，理论VSNK肽在2.7 min(m/z=447.26)，脱酰胺VSNK肽(m/z=448.24)却分别在3.2和3.3 min。MS/MS谱图可清楚地鉴定三种肽的真实性。

[图片]

为进一步确认N325脱酰胺的鉴定和定量，用Glu-C替代胰蛋白酶。

如 图6 ，一个15个残基的肽319-YKCKVSNKALPAPIE-333在23.5 min洗脱，两个脱酰胺肽分别在23.2和24.2 min洗脱。Glu-C比例与胰蛋白酶肽图结果一致，表明本文献的胰蛋白酶肽图可以检测N325脱酰胺产物并准确定量PTM比例。

讨论部分

PART 03

Technology

1. N325脱酰胺为何影响ADCC活性？

前期有报道，Fc与受体之间的结合，其中一个关键元素是由 Fc的P329 与受体的W90和W113形成疏水核心。作为确定界面中的主要接触区域之一， P329周围的疏水核心对ADCC功能起关键作用 ，该残基的丙氨酸替换会消除结合并废除ADCC活性；邻近氨基酸的干扰(例如K322的丙氨酸替换)也会导致FcγRIIIa结合亲和力和ADCC功能降低。

N325紧邻P329 ，提示N325脱酰胺可能改变局部三维结构，从而可能改变结合界面或干扰Fc与其受体之间的结合界面，导致ADCC活性丧失。

2. 关于N325脱酰胺

N325未成为许多降解研究的焦点，因为它不符合容易发生脱酰胺的 常规基序 ，如 Asn-Gly、Asn-Ser、Asn-Thr和Asn-Asn 。

直到2006年，Liu等 【2】 才首次报道N325脱酰胺；

Pace等 【3】 发现Fc脱酰胺速率的pH依赖性在pH 6.3时最低， pH约5.5时N325 脱酰胺速率更高；

Yan等 【4】 揭示了N325的溶剂可及性与pH之间的负相关，在中性pH下该位点埋藏在局部三维结构中， 仅在酸性pH下暴露，随后在高温下发生脱酰胺 ，这解释了为什么N325脱酰胺仅在制剂缓冲液和热应激条件下发生。

3. 重视N325脱酰胺

由于N325脱酰胺主要发生在低pH和高温应激条件下，它不太可能在受控生产工艺或适当控制的储存和运输条件下发生。然而，对于ADCC效应功能是 作用机制 的抗体或Fc融合蛋白， N325脱酰胺被视为 CQA 。因此，应建立适当的风险评估和控制策略，以确保产品安全性和有效性。

此外，当不需要ADCC时，单独突变N325位点或与糖工程结合，可能有助于降低分子的ADCC。

4. 回到实操：N325脱酰胺怎么测准？

本质上是两个技术环节的考验：一是Trypsin酶解能否稳定、特异地产出VSNK短肽并避免自酶解干扰，二是电荷变异体分离能否把富含N325脱酰胺的酸性组分有效富集出来。方法链上任何一环不够稳健，后续的定量和CQA评估都缺乏可靠基础。

针对这两个环节， 泳拓生物提供 质 谱级Trypsin酶 ，纯度≥95%，自酶解程度低、非特异性剪切水平低，适用于抗体类样品的肽图分析，有助于VSNK这类短肽的稳定检出。针对电荷变异体表征，泳拓的 CEX pH Gradient Buffer 专为阳离子交换柱上mAb电荷变异体分离设计，可减少流动相调整的方法开发时间； 配套的电荷异质性分析试剂 （包括CIEF所需的标准品、电极液、增溶剂等）覆盖从IEC到cIEF的电荷变异体表征场景。

工具解决的是“能不能测准”的问题。N325脱酰胺真正值得重视的，仍然是它作为ADCC关键质量属性的定位。对于作用机制包括ADCC的产品而言，充分理解N325脱酰胺的关键性并进行适当监测，有助于确保IgG1或Fc融合产品的安全性和有效性。
