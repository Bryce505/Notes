- **摘要**：文章从药品 GMP 数据完整性（Data Integrity）管理视角，系统梳理 QC 实验室 Excel 计算表格的合规验证方案。作者依据《药品记录与数据管理要求（试行）》、GMP 计算机化系统附录、EDQM OMCL PA/PH/OMCL (08) 87 R6 及 EU GMP Annex 11，提出核心判断标准：只要 Excel 用于 GMP 数据计算、支撑产品放行决策，就应纳入计算机化系统管理并验证。内容涵盖：建立表单清单、唯一编号、版本控制与用途说明的管理体系；颜色区分录入与计算区、超限提示、自动修约、只读权限、独立软件比对、输入范围限制等常见验证项目；ALCOA+ 各要素与具体控制措施的对应；验证方案七要素（目的、范围、职责、公式清单、公式位置、验证程序、验收标准）；cell、sheet、workbook、folder 四级受控与存储存档要求；以及 EU GMP 附录 11 问答中的模板、准确性检查、边界检查与再验证要点。

  - 判断 Excel 是否需要验证的标准是它是否支撑 GMP 数据与放行决策，而非软件本身的大小或复杂程度。

- **是否值得读**：针对受监管实验室的真实合规场景，给出可落地的验证要素、控制清单与存档规则，信息密度高且方法可直接迁移使用。

## 单抗Fc上Met氧化对产品质量有什么影响？
- **剪藏**：2026-11-24 12:09 ｜ **发布**：2026-11-24
- **优先级**：高 ｜ **状态**：未读
- **关键词**：甲硫氨酸氧化 / 单克隆抗体 / 电荷异质性 / CDC活性 / FcRn亲和力 / 强制氧化
- **摘要**：文章解读浙江大学团队2026年发表于《Journal of Chromatography B》的研究，评估甲硫氨酸氧化对单抗mAb A在5°C储存1.5年及强制氧化条件下的结构与功能影响。用LC-MS肽图、CEX、HIC、SEC、nrCE-SDS、DLS及BLI亲和力、报告基因ADCC、CDC和鼠模型药效/药代等正交方法，发现M253和M429优先氧化（储存样品达53.5%和22.1%），伴随碱性峰增加与疏水性增强且与氧化水平线性相关，但聚体、片段和构象稳定性无显著变化。功能上CDC活性下降约70%，FcRn亲和力降低3.2倍，而ADCC、FcγRIIIA与C1q结合、体内抗肿瘤疗效和PK均未受显著影响。结论是氧化改变理化性质但不损害mAb A以ADCC为主要机制的基本生物学功能，且强制氧化可模拟长期储存氧化进程。
- **洞见**：
  - M253/M429氧化显著改变电荷与疏水性，却不引起聚集或片段增加，说明理化性质变化不等于稳定性风险。
  - CDC活性下降70%但C1q结合不变，原因是氧化破坏CH2-CH3界面构象、阻碍IgG六聚化，故C1q结合数据不能替代CDC直接检测。
  - FcRn亲和力下降3.2倍而半衰期不变，说明FcRn亲和力是半衰期的必要非充分预测指标，存在阈值效应。
  - 若CDC仅为次要作用机制，体外活性下降未必转化为体内疗效损失，功能相关性应结合MOA判断。
- **是否值得读**：以完整正交数据回答“修饰超标是否等于质量风险”这一实际难题，并给出C1q不能替代CDC、FcRn亲和力非充分预测等可迁移判断方法，对生物药CMC与质量评价有直接参考价值。

## Super-agent 设计探索：迈向更自主的 Agent 系统
- **剪藏**：2026-11-23 05:36 ｜ **发布**：2026-10-31
- **优先级**：高 ｜ **状态**：未读
- **关键词**：Super-agent / 双层架构 / 事件驱动 / 存算分离 / 上下文管理 / Agent 系统设计
- **摘要**：本文是 DeepSeek Harness 团队面向工程实践的架构探讨，指出当前单 Session Agent 的瓶颈已从模型能力转向人的注意力——一个人只能同时跟进 3 到 5 个活跃会话。为此作者提出 Super-agent 形态，要求具备连续、高效、主动、持久四个特征，并给出五个模块：双层架构（常驻 Router 层统一承接人类交互与任务分派，上下文隔离的 Worker 层并发执行）、事件驱动（Trigger 经程序层+语义层两级过滤，通过订阅与直通路由到 Worker，用 Inline & Spill 与链式召回组织上下文，并以投机执行提前行动）、异步全双工 ReAct Loop 与按信道定制输出、计算/状态/环境两层解耦实现云端持久在线、外部 Watchdog 做任务级监控自愈。消融实验显示完整方案任务完成 p50 为 12.4 分钟，显著优于带 Subagent 工具的单 Session；去掉直通使 Router 决策量增加约 30%、token 增加约 37%；Router 批处理在高负载下把单个决定分摊的推理时间从 6.4 秒降至 1.6 秒。
- **洞见**：

- **摘要**：文章以QbD闭环为框架，说明单抗控制系统的搭建逻辑：从QTPP和CQA识别出发，建立货架期末CQA-AC并内收紧5%形成CQA-TR，再结合工艺表征与属性测试策略ATS，按风险将属性分为放行检测、监控和不测试。CQA-AC制定强调临床暴露量和累积影响，工艺影响分数用1/2/4/10决策树评估丰度、模型可预测性及PC/PV最坏结果。文中用去岩藻糖化、Fc氧化、Protein A残留和CDR糖基化四个案例展示ATS计算与策略选择，并总结监控纳入PALM、变更后复评及退出监控等经验。
