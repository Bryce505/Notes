  - USP〈1033〉要求用置信区间替代点估计进行验证判定，并明确区分方法（Method）与程序（Procedure），通过方差分量设计重复策略可显著降低报告结果变异。

## 双特异性抗体纯化中 Knob‑into‑Hole（杵‑臼）技术相关杂质的研究
- **剪藏**：2026-08-20 22:31 ｜ **发布**：2026-08-15
- **优先级**：高 ｜ **状态**：未读
- **关键词**：双特异性抗体 / Knob-into-Hole / 假KiH现象 / 阳离子交换层析 / 同源二聚体杂质 / 纯化工艺
- **摘要**：本文研究双特异性抗体纯化中与Knob‑into‑Hole（KiH）技术相关的杂质去除问题。KiH技术通过重链上的“杵”和“臼”突变促进异二聚体形成，但生产过程中仍会生成杵‑杵和臼‑臼同源二聚体杂质。研究发现，将分别含杵、臼组分的细胞上清混合后，常规检测会误判为形成目标异二聚体，但深入表征证实该组装为“假KiH”，仅靠非共价作用力结合，并非功能性分子，且亲和层析对未混合样品的杂质去除无效。通过对比多种纯化策略，作者验证了阳离子交换层析（CEX）利用目标分子与杂质的pI差异，在适宜pH下可有效去除杵相关杂质（含量下降17%）和臼相关杂质（流穿模式去除），同时将功能性KiH纯度提高至96%以上，并将后续AEX改为流穿模式，载量大幅提升至300 g/L。研究强调CEX工艺的分离效果高度依赖分子间pI差异，不具备普适性，为双抗纯化工艺开发提供了实践依据。
- **洞见**：
  - 假KiH现象：杵‑杵和臼‑臼同源二聚体混合后可形成非共价复合物，常规检测误判为异二聚体，需用变性条件（如非还原SDS‑Caliper）鉴别真实组装。
  - 亲和层析仅对预先混合的样品降低KiH相关杂质，对未混合样品无效，提示杂质去除依赖真正的异二聚化。
  - 利用pI差异，阳离子交换层析在pH 7.5或5.5条件下可有效分离目标双抗与杵/臼杂质，将功能性KiH纯度提升至96%以上，并实现AEX流穿模式载量大幅提升。
  - CEX工艺效果高度依赖特定分子的pI差异，不具有普适性，需针对目标分子进行系统优化。
- **是否值得读**：文章揭示了双抗纯化中罕见的“假KiH”现象，并提供可操作的CEX除杂策略，信息密度高且对生物制药工艺开发有直接参考价值。

## 质谱裂解规律——McLafferty 重排
- **剪藏**：2026-08-20 22:18 ｜ **发布**：2026-08-13
- **优先级**：高 ｜ **状态**：未读
- **关键词**：McLafferty重排 / 质谱裂解 / 六元环过渡态 / γ-H迁移 / 特征碎片峰
- **摘要**：本文系统讲解质谱分析中 McLafferty 重排的核心原理与必要条件。重排的本质是六元环过渡态，γ-氢迁移至杂原子，同时β位C-C键断裂，生成烯酮/烯醇碎片和中性烯烃。作者强调三个缺一不可的条件：γ位有氢、含π键杂原子（如C=O）、β键可断。通过四个案例（4-甲基-2-戊酮、丁酸、2-甲基-2-丁醇等）展示典型碎片峰（如m/z 58、60），并提醒无γ-H时α-断裂和i-断裂仍是主要途径。文末给出实用建议：遇到酮/醛/酸质谱图，先找M-烯烃的偶数质量特征峰。
- **洞见**：
  - 麦氏重排是'先搬家后分家'，区别于α-断裂的一刀切，其产物是偶数电子离子和中性烯烃。
  - 反应必须同时满足γ-H、π杂原子和可断β键三个条件，缺一不可。
  - 酮类化合物若出现m/z 58基峰，基本可判定发生了麦氏重排，这是快速识别质谱图的有效信号。
  - 无γ-H时麦氏重排不发生，但α-断裂和i-断裂仍可进行，需结合其他裂解规律综合分析。
- **是否值得读**：文章将McLafferty重排的原理和条件讲得清晰透彻，并用案例给出可操作的特征峰判据，对质谱解析有直接指导价值，信息密度高。

## ADC质谱表征过程中，常见的挑战及实用方法举例
- **剪藏**：2026-08-20 22:14 ｜ **发布**：2026-08-17
- **优先级**：高 ｜ **状态**：未读
- **关键词**：ADC / 质谱表征 / 完整分子量 / 亚基分析 / 肽图 / 连接子-有效载荷
- **摘要**：本文基于辉瑞公司2018年发表在mAbs上的综述，总结了ADC质谱表征中常见的6种挑战及解决方法。内容涵盖完整分子量、亚基分子量和肽图三个层面。具体挑战包括：半胱氨酸偶联ADC在变性条件下解离，需采用Native SEC-MS检测完整四链；酸不稳定连接子需通过调整流动相pH防止断裂；表面暴露的连接子-有效载荷（LP）在ESI源中易发生裂解，需优化锥孔电压等参数；疏水性LP导致C4柱上回收率差，二苯基柱可显著改善；马来酰亚胺偶联ADC在酶解时需控制pH以防止开环假象。文章强调，针对不同类型ADC的独特性质精细调节LC/MS方法，可获得高质量表征数据，对工艺和产品质量控制至关重要。
- **洞见**：
  - 传统的mAb LC/MS方法并不直接适用于ADC，需针对偶联物特有的不稳定键、疏水性和表面可及性进行调整。
  - 通过提高流动相pH（如用甲酸替代TFA）可有效保留酸不稳定的连接子-有效载荷，获得完整ADC的准确分子量。
  - 对于疏水性强的连接子-有效载荷，二苯基柱相比C4柱能显著提高修饰亚基的回收率。
  - 在肽图分析中，将消化缓冲液pH从8.2降至7.5可避免马来酰亚胺开环产生的+18 Da人为修饰峰。
- **是否值得读**：文章提供了多种ADC质谱表征中具体问题及可操作的解决方法，信息密度高，对相关领域研究者具有直接参考价值。

## 基于 Protein A 纯化的填料选型、淋洗与洗脱参数的优化
- **剪藏**：2026-08-20 22:00 ｜ **发布**：2026-08-19
- **优先级**：高 ｜ **状态**：未读
- **关键词**：Protein A 纯化 / 高通量筛选 / 填料选型 / 洗脱 pH / HCP 去除 / 抗体聚集
- **摘要**：本文针对抗体药物下游纯化中 Protein A 层析的工艺优化问题，提出利用自动化液体处理平台配合预装填料的 dSPE 枪头进行高通量微量筛选的方法。研究以 4 种 Protein A 填料为对象，系统评估了 IgG 结合动力学、最大结合容量、淋洗缓冲液组成及洗脱 pH 对 HCP 去除、抗体收率及聚集体水平的影响。结果表明，枪头模式结合容量与批次实验及厂家数据基本一致；碱性 Tris-NaCl 淋洗可有效去除 HCP 且不损失收率；HipH 填料在温和洗脱 pH 下能保持较高收率并显著降低聚集体，适合易聚集的双抗和单抗。组合优化淋洗与洗脱条件后，产物 HCP 水平可低至 3.5-5.3 ppm，达到上市抗体标准。该微型自动化平台可在 2.5 小时内完成 96 个样品纯化，显著缩短开发周期，为放大生产提供依据。
- **洞见**：
  - dSPE 枪头结合自动化平台可实现微量、高通量的 Protein A 条件筛选，其结合容量与批次实验、厂家数据一致，可支持放大工艺开发。
  - 碱性 Tris-NaCl 中间淋洗能在不损失抗体收率的前提下显著去除 HCP，而强变性淋洗虽除杂效果好但会大幅降低收率。
  - 洗脱 pH 与填料类型共同决定收率与聚集水平：HipH 填料在 pH 4.4 温和洗脱下可维持高收率并大幅减少 HMW，尤其适用于易聚集的双抗和 mAb2。
  - 不同抗体分子的 HCP 本底和聚集倾向差异大，任何新分子都必须通过实际筛选来优化淋洗和洗脱条件，不能直接套用已有方案。
- **是否值得读**：文章提供了系统的实验数据和可迁移的高通量筛选方法，对单抗/双抗下游工艺开发具有直接指导价值，信息密度高且结论具体。

## Cpk为什么要大于1.33？1.33和1.67 这两条线是谁定的
- **剪藏**：2026-08-20 21:15 ｜ **发布**：2026-08-20
- **优先级**：高 ｜ **状态**：未读
- **关键词**：Cpk / 过程能力 / 西格玛水平 / 不良率 / 1.33 / 1.67
- **摘要**：文章围绕Cpk判定标准1.33和1.67展开，解答其来源与含义。首先通过推导Cpk=Z/3，明确1.33对应西格玛水平4，双侧不良率约63PPM；1.67对应5σ，双侧不良率约0.57PPM。指出这些标准并非拍脑袋制定，而是行业长期沉淀的“可接受风险”约定，汽车供应链通常以Cpk≥1.33为量产门槛，特殊特性要求≥1.67。同时引入1.5σ漂移概念，说明短期与长期不良率的差异，并给出Cpk分级管理建议（<1.0停线改善，1.0-1.33改善，1.33-1.67监控，≥1.67重点管控）。最后强调标准以顾客要求为准，并推广六西格玛培训。
- **洞见**：
  - Cpk=1.33对应西格玛水平4，双侧不良率约63PPM，是质量与成本平衡的行业约定。
  - 1.33是长期量产底线，1.67是为新项目预留的缓冲，因为过程均值会漂移1.5σ。
  - Cpk分级可直接转化为管理动作：小于1.0立即停线改善，1.0-1.33纳入改善计划，1.33-1.67正常监控，大于1.67重点管控。
  - 判定标准本质是“可接受风险”的行业共识，实际需以顾客图纸和控制计划为准。
- **是否值得读**：文章从数学推导到工程实践，清晰解释Cpk=1.33的来源，并提供可操作的分级管理方法，信息密度高，对质量人员有实际指导价值。
